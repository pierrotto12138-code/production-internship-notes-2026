# 2026-09-15 · IF 语句练习：输入整数判断时间段（ELSEIF 多分支）

> **来源**：实操（示教器 FlexPendant，程序 `Module1/time_period`）+ 官方手册《RAPID 语言内核技术参考手册》（**IF 语句**）。
> **练习要求**：**输入一个整数，显示对应时间段**——
> 0–5 显示**凌晨**，6–11 **上午**，12–17 **下午**，18–23 **晚上**，**其他显示 NG**。
> **指令提示**：`IF <EXP> THEN` / `ELSEIF <EXP> THEN` / `ELSE` / `ENDIF`（**多分支结构**）。
> **本日成果**：用 `IF…ELSEIF…ELSE…ENDIF` 完成**五路分支**判断，掌握了"**区间用 AND 两侧限**"和"**ELSE 兜底非法值**"两个要点。

![IF 多分支练习：时间段判断（PPT）](../../配图/Day4_images/image-0915_if_time_period_ppt.jpg)

## 一、程序原文（示教器实际代码）

```rapid
	PROC time_period()
		VAR num timeval;               ! input value
		VAR num key;
		TPErase;
		TPReadNum timeval, "time?";
		IF timeval >= 0 AND timeval <= 5 THEN
			TPWrite "dawn";            ! 0-5
		ELSEIF timeval >= 6 AND timeval <= 11 THEN
			TPWrite "morning";         ! 6-11
		ELSEIF timeval >= 12 AND timeval <= 17 THEN
			TPWrite "afternoon";       ! 12-17
		ELSEIF timeval >= 18 AND timeval <= 23 THEN
			TPWrite "evening";         ! 18-23
		ELSE
			TPWrite "NG";              ! others: invalid
		ENDIF
		TPReadFK key, "Done. Press OK to finish", "", "", "", "OK", "";
	ENDPROC
```

**运行效果**（对照 PPT 例子）：输入 `13` → 显示 `afternoon` ✅

## 二、★ 要点一：区间判断必须"两侧都限"

想表示"0 到 5 之间"，**不能**写成数学上的连写：

```rapid
IF 0 <= timeval <= 5 THEN      ! ❌ RAPID 不支持这种连写
```

RAPID **没有** Python 那种链式比较，**必须用 `AND` 把两个比较连起来**：

```rapid
IF timeval >= 0 AND timeval <= 5 THEN      ! ✅ 正确
```

> 这就是为什么**每一段都要写两个条件**。区间判断是最常见的写法错误来源。
> 另外：`AND` / `OR` / `NOT` / `XOR` 是 RAPID 的逻辑运算符（保留字），用在条件里。

## 三、★ 要点二：`ELSEIF` 是"连续求值、第一个为真就执行"

**手册原文**（IF 语句）：

> **"条件表达式将连续进行求值，直至其中一个求值为真。然后，将执行相应的语句表。如果没有任何条件表达式求值为真，那么将执行（可选）else 子句。"**

所以：
- 分支**从上到下依次判断**，**第一个为真的执行完就跳出**，后面的不再判断；
- 本练习的四个区间**互不重叠**，所以顺序无所谓、结果唯一；
- **但一旦区间重叠，靠前的分支会"截胡"**（后面的永远轮不到）——写多分支时要注意这个陷阱。

## 四、★ 要点三：`ELSE` 兜住所有非法值

```rapid
		ELSE
			TPWrite "NG";              ! others: invalid
		ENDIF
```

**`ELSE` 是本题"其他为 NG"的落点**。没有它的话：
- 输入 **负数**（如 −5）、**超大值**（如 100）→ **一条分支都不命中** → 什么都不输出；
- 加了 `ELSE` → 统统落到 `NG`，**行为可预期**。

> **经验**：`ELSE` 不只是"剩下的情况"，更是**兜底**——防止非法/意外输入时程序毫无反应。写多分支判断时**养成加 `ELSE` 的习惯**。

## 五、和同日"求最小值"那篇的对照

同一天练了两道 IF 题，正好覆盖 IF 的两种用法：

| | 求最小值（`min_of_three`） | 判断时间段（本篇） |
|---|---|---|
| IF 形态 | **两条独立 IF**（各判一次） | **一条 IF + 三个 ELSEIF + ELSE** |
| 思路 | **擂台法**（逐个挑战） | **多分支分类**（按区间归类） |
| 关键点 | 临时变量/比较替换 | **区间两侧限 + ELSE 兜底** |
| 适用 | 求最值、累积判断 | **按区间/类别分流** |

> 前者是"**判断后继续**"，后者是"**判断后分路**"——**IF 的两种典型用途**。

## 六、要点串记

- **区间判断用 `AND` 两侧限**：`x >= 0 AND x <= 5`，**不能连写**。
- **`ELSEIF` 从上到下连续求值，第一个为真就执行**；区间重叠时靠前的优先。
- **`ELSE` 要兜底**所有非法/意外值（本题的 `NG`），避免程序毫无反应。
- **多分支分类场景**用 `IF…ELSEIF…ELSE…ENDIF`；**简单判断**用独立 `IF…ENDIF`（如擂台法）。
- **提示与注释用英文**（RAPID 是 ISO 8859-1，汉字变 `?`）。
