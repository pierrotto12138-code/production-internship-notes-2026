# 2026-09-16 · 嵌套循环练习：画六个圆（两排 × 每排三个）

> **来源**：实操（RobotStudio 6.08 虚拟控制器 `260913System1`，`Module1/draw_circles`）+ 官方手册《RAPID 语言内核技术参考手册》（**For 语句**）。
> **任务要求**：把 0915 的"三个连续的圆"**扩充为六个圆，分两排、每排三个**。
> **本日成果**：第一次使用**嵌套 FOR 循环**（外层管"排"、内层管"列"），**代码行数不变（仍是 3 行指令）**，只多两行循环头尾就实现了"二维阵列"。

## 一、程序原文（控制器实际代码，`Module1/draw_circles`）

```rapid
    PROC draw_circles()
        VAR num i;
        VAR num j;
        FOR j FROM 0 TO 1 DO
            FOR i FROM 0 TO 2 DO
                MoveJ Offs(Target_160,i*40,j*40,0),v50,z0,MyTool\WObj:=wobj0;
                MoveC Offs(Target_160,i*40+20,j*40-20,0),Offs(Target_160,i*40,j*40-40,0),v50,z0,MyTool\WObj:=wobj0;
                MoveC Offs(Target_160,i*40-20,j*40-20,0),Offs(Target_160,i*40,j*40,0),v50,z0,MyTool\WObj:=wobj0;
            ENDFOR
        ENDFOR
    ENDPROC
```

## 二、★ 核心：嵌套循环 = 二维阵列

**从"三个圆"到"六个圆"的关键，不是把代码复制两遍，而是给位置加"第二个维度"**：

| | 0915（3 个圆） | **0916（6 个圆）** |
|---|---|---|
| 循环 | 一层 `FOR i` | **两层：`FOR j`（排）× `FOR i`（列）** |
| 位置 | `i*40` 只动 X | **X 用 `i*40`、Y 用 `j*40`** |
| 指令行数 | 3 行 | **仍是 3 行**（只多 2 行循环头尾） |
| 圆的数量 | 3 | 6 |

**写法上的唯一改动**：把每个点的 **Y 坐标从常量 `0` 换成 `j*40`**（第二排整体沿 Y 平移）。

**嵌套的执行顺序**（`j` 外层、`i` 内层）：
```
j=0:  i=0,1,2  → 画第一排的 3 个圆
j=1:  i=0,1,2  → 画第二排的 3 个圆
```
即**先画完一整排，再画下一排**。

## 三、几何自检（我逐点算过）

以 `Target_160` 为第一排第一个圆的**顶点**，半径 `r=20`：

| 排 `j` | 圆 `i` | 顶点 (x, y) | 圆心 (x, y) |
|--------|--------|-------------|-------------|
| 0 | 0 | (0, 0) | (0, −20) |
| 0 | 1 | (40, 0) | (40, −20) |
| 0 | 2 | (80, 0) | (80, −20) |
| 1 | 0 | (0, **40**) | (0, **20**) |
| 1 | 1 | (40, **40**) | (40, **20**) |
| 1 | 2 | (80, **40**) | (80, **20**) |

```
     j=1      ○   ○   ○        ← 第二排（y = +40 那侧）
              ○   ○   ○        ← 第一排（从 Target_160 起）
     j=0      ↑
            Target_160
```

**相切校验**：
- **横向**：相邻圆心距 = 40 = **2r** → 相切 ✅
- **纵向**：两排圆心 y 差 = 40 = **2r** → 也相切 ✅

> 所以 **`j*40` 这个 40 不是随便取的**——它等于 `2r`，保证上下两排**刚好相切**（与横向一致的间距）。

## 四、嵌套 FOR 的注意点（手册确认）

0915 已经查过的 FOR 三条约束，**嵌套时同样适用**（手册 For 语句）：

| 约束 | 说明 |
|------|------|
| **循环变量只读** | 手册："**是只读的，即，无法被 for 循环的语句更新**"——`i`、`j` 都不能在循环体内改 |
| **`FROM/TO/STEP` 只求值一次** | 手册："**它们只求值一次**"——循环次数开局定死 |
| **`STEP` 是保留字** | 不能拿它当变量名 |

**嵌套新增的注意点**：
1. **两个循环变量必须不同名**（`i` 和 `j`）——否则内层会**隐藏**外层同名变量（手册：程序数据"在范围内会隐藏名称相同的其他程序或数据"），逻辑就乱了；
2. **内外层变量都要声明**：`VAR num i; VAR num j;` —— 漏一个就是"未声明的标识符"（0915 踩过这个坑）。

## 五、和"复制两份"方案的对比

要画六个圆，**最笨的办法是把三个圆的代码复制一遍、把 Y 坐标手改**：

| 方案 | 代码量 | 改动位置 | 出错风险 |
|------|--------|---------|---------|
| 复制两份 | 6 行指令 + 6 行 `Offs` 手改 Y | 分散在 6 处 | **高**（漏改一处就错位） |
| **嵌套循环** | **3 行指令** | **只有 `j*40` 这一处模式** | **低** |

> 这和 0915「三个圆 vs 9 行展开版」是同一个道理——**"重复的结构"用循环表达，而不是靠复制**。
> **扩展性**：想改成"三排"只需 `FOR j FROM 0 TO 2`；想改成"每排 4 个"只需 `FOR i FROM 0 TO 3`。

## 六、⚠️ 两个需要现场确认的点

**① 第二排的方向（`+Y` 还是 `−Y`）**
本程序把第二排放在**第一排的 `+Y` 侧**（`j*40`）。**如果工件在 `−Y` 侧才有空间**，需要把 **3 处 `j*40` 改成 `-j*40`**。

> 判断方法：看 `Target_160` 周围哪边有 ≥40 mm 余量；先跑一次看轨迹方向，不对就翻符号。

**② 运行验证状态**
代码已录入控制器（模块 `0015CEBD`，14:07），但**本次尚未获得运行后的轨迹确认**（0915 的"三个圆"是用 TCP 跟踪截图确认过的）。**上机/仿真跑一次、用 TCP 跟踪看一眼是不是六个相切的圆**即可确认。

## 七、要点串记

- **嵌套 FOR 实现二维阵列**：外层管排（`j`）、内层管列（`i`），位置写成 `(i*dx, j*dy)`。
- **六个圆仍是 3 行指令** —— 只多两行循环头尾，**没有复制代码**。
- **间距取 `2r`（=40）保证相切**：横向、纵向都用 40。
- **嵌套注意**：两循环变量**不能同名**，且**都要声明**。
- **`j*40` 的符号决定第二排在 `+Y` 还是 `−Y` 侧**，需按现场空间确认。
- **确认方法**：跑一次 + **TCP 跟踪**看轨迹（`Offs` 的目标点在图形里不可见，只能靠跟踪看实际路径）。
