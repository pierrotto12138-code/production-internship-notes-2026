# 2026-09-14 · 软件完成以 Offs 为功能基础的轮廓遍历

> **来源**：实操（**RobotStudio 6.08 离线工作站 `260913Study1`**，虚拟控制器 `260913System1`）+ 官方手册《RAPID 指令、函数与数据类型》（`Offs`、`zonedata`）。
> **本日成果**：在**软件（离线编程）里**用 `Offs()` 完成了**轮廓遍历**——只示教**一个**基准点，其余三个角点靠 `Offs` 算出来，最后一条 `MoveL` 回基准点，走出**闭合矩形轮廓** `Path_20`。
> **一句话**：**1 个基准点 + 3 条 `Offs` + 1 条回基准点 = 一个 400 × 300 的闭合矩形**（`Path_20`）。

## 一、程序原文（工作站 `Module1.mod` 导出，与截图一致）

```rapid
PROC Path_20()
    MoveL Target_300,                  v200, z0, MyTool\WObj:=wobj0;  ! 45 基准点（唯一示教的点）
    MoveL Offs(Target_300, 400,   0, 0), v200, z0, MyTool;            ! 46 角2：X 偏 +400
    MoveL Offs(Target_300, 400, 300, 0), v200, z0, MyTool;            ! 47 角3：X 偏 +400、Y 偏 +300
    MoveL Offs(Target_300,   0, 300, 0), v200, z0, MyTool;            ! 48 角4：Y 偏 +300
    MoveL Target_300,                  v200, z0, MyTool;              ! 49 回到基准点（闭合）
ENDPROC
```

## 二、轨迹形状：一个 400 × 300 的闭合矩形

把四个点都换算成"**相对 `Target_300` 的偏移量**"：

| 顺序 | 指令点 | 相对 `Target_300` (ΔX, ΔY, ΔZ) | 角 |
|------|--------|-------------------------------|----|
| ① | `Target_300` | (0, 0, 0) | 角 A |
| ② | `Offs(Target_300,400,0,0)` | (400, 0, 0) | 角 B |
| ③ | `Offs(Target_300,400,300,0)` | (400, 300, 0) | 角 C |
| ④ | `Offs(Target_300,0,300,0)` | (0, 300, 0) | 角 D |
| ⑤ | `Target_300` | (0, 0, 0) | 回到角 A |

- **Z 分量始终为 0** → 四点共面，落在工件坐标系的 **X–Y 平面**；
- **X 走 400 mm、Y 走 300 mm** → **一个 400 × 300 的矩形**；
- **首尾闭合** → 是一条可以**反复执行**的轮廓轨迹。

```
 角A (0,0) ──→ 角B (400,0)
    ↑                    │        ┌ 400 × 300 矩形
 角D (0,300) ←── 角C (400,300)
```

## 三、★ 关键点：`Offs` 让"示教一条轮廓"变成"算一条轮廓"

| | `Path_10`（0913 轮廓巡点） | `Path_20`（本日，软件） |
|---|---|---|
| 点从哪来 | 沿轮廓**逐个示教**（`Target_160…280`） | **只示教 1 个**（`Target_300`），其余靠 `Offs` **算** |
| 转弯区 | `z100`（飞越点，圆滑过渡，角是圆的） | **`z0`**（0.3 mm，近乎精确到位 → **角是尖的**） |
| 说明 | 贴合"任意形状的实际轮廓" | 贴合"规则形状"（矩形/阵列），**改动维度只需改偏移量** |

> **`z0` 的含义**（手册 `zonedata` 预定义数据表）：`z0` 的 TCP 路径区域半径 = **0.3 mm**——比 `z1`(1 mm)、`z20`(20 mm) 都精细，所以**接近精确停**，四个角能"走方"；而 `Path_10` 用的 `z100`(100 mm) 是大飞越区，角会被**抹圆**。
> **选 `z` 的经验**：**要走尖角/规则形状 → 小 `z`（如 `z0`）；要做圆滑的周边往复 → 大 `z`（如 `z100`）**。

## 五、要点串记

- **`Offs` 做轮廓遍历**：**1 个基准点 + N 个偏移量** → 规则轮廓（矩形/阵列）**不用逐个示教**。
- **本日矩形**：400 × 300，位于工件坐标系 **X–Y 平面**，X 走 400、Y 走 300，首尾闭合。
- **`z0` = 0.3 mm**（近乎精确到位）→ **走尖角**；`z100` 会把角抹圆 → **走圆滑**。**按形状选 `z`**。
- **`Offs` 沿工件坐标系偏移**，`\WObj` 一换方向就变。
- **软件与真机同构**：先离线把轨迹调好（软件），再上真机跑（`dh0914r2`），这是离线编程的标准用法。
