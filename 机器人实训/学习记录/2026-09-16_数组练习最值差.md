# 2026-09-16 · 数组练习：输入 8 个数求最大值与最小值的差

> **来源**：实操（RobotStudio 6.08 虚拟控制器 `260913System1`，模块 `ArrayEx`）+ 官方手册《RAPID 语言内核技术参考手册》（**变量 · 数组元素**）、《RAPID 语言概览技术参考手册》（**表达式 · 数组**）。
> **练习要求**：**通过示教器依次输入 8 个整数**，**输出最大值与最小值的差**。
> **本日成果**：第一次使用 **RAPID 数组**（`VAR num a{8};`），把 0915 的**擂台法与循环结合**升级为"对数组求最值"，并**运行验证通过**（`Diff=40`）。

![数组练习要求（PPT）](../../配图/Day5_images/image-0916_array_exercise_ppt.jpg)

## 一、程序原文（控制器实际代码，模块 `ArrayEx`）

```rapid
MODULE ArrayEx
    PROC max_min_diff()
        VAR num a{8};
        VAR num i;
        VAR num vmax;
        VAR num vmin;
        VAR num key;
        TPErase;
        FOR i FROM 1 TO 8 DO
            TPReadNum a{i},"Num?";
        ENDFOR
        vmax:=a{1};
        vmin:=a{1};
        FOR i FROM 2 TO 8 DO
            IF a{i}>vmax THEN
                vmax:=a{i};
            ENDIF
            IF a{i}<vmin THEN
                vmin:=a{i};
            ENDIF
        ENDFOR
        TPWrite "Diff="\Num:=vmax-vmin;
        TPReadFK key,"Done. Press OK to finish","","","","OK","";
    ENDPROC
ENDMODULE
```

## 二、★ 关键点一：RAPID 数组**从索引 1 开始**（不是 0）

这是本题**最容易错**的地方。手册原文（《RAPID 语言内核技术参考手册》→ 表达式 → 变量）：

> **"索引表达式必须表示为一个大于0的整数值（参见 num型）。索引值 1 是指选择数组的第一个元素。索引值不可有悖于声明的维度。"**

《RAPID 语言概览技术参考手册》也一样：

> **"索引号为大于0的整数值……索引值 1 对应的是第一个元素。"**

**所以**：

| 写法 | 是否合法 |
|------|---------|
| `VAR num a{8};` → 元素为 `a{1}` … `a{8}` | ✅ 合法范围 1~8 |
| `a{0}` | ❌ **非法**（索引必须 > 0） |
| `a{9}` | ❌ 非法（超出声明的维度 8） |

**直接影响循环写法**：
```rapid
FOR i FROM 1 TO 8 DO        ← ✅ 正确（1 起）
FOR i FROM 0 TO 7 DO        ← ❌ 错误（会用到 a{0}）
```

> ⚠️ **对习惯 C / Python 的人来说这是必须改掉的思维定式**——那两门语言数组/列表从 0 开始，**RAPID 从 1 开始**。

## 三、关键点二：数组的声明与引用语法

**声明**（手册）：`VAR num a{8};` —— 花括号里是**维度**（元素个数）。

**引用整个数组**：
```rapid
row := column;      ← 手册示例：整个数组可以直接赋值
```

**引用单个元素**：`a{i}` —— 花括号里是**索引表达式**，可以是变量（手册示例 `mat{i * 10, j}`）。

> 这对本题很关键：**循环变量可以直接做索引** `a{i}`，所以"读入 8 个数"和"逐个比较"都能用循环统一处理。

## 四、算法：两趟循环 + 擂台法

| 趟 | 范围 | 干什么 |
|----|------|--------|
| **第一趟** | `1 → 8` | `TPReadNum a{i}, "Num?";` **依次读入 8 个数**存进数组 |
| **第二趟** | `2 → 8` | **擂台法**同时找 `vmax` 和 `vmin` |
| 收尾 | — | `TPWrite "Diff=" \Num := vmax - vmin;` **输出差值** |

**第二趟的三个设计要点**：

1. **擂台初始值用 `a{1}`** —— 先假设"第一个数既是最大也是最小"：
   ```rapid
   vmax:=a{1};
   vmin:=a{1};
   ```
2. **从 `2` 开始挑战** —— 因为 `a{1}` 已经当过擂主了，再跟自己比没意义：
   ```rapid
   FOR i FROM 2 TO 8 DO
   ```
3. **一次循环同时维护两个最值** —— 两个 `IF` 各管一头（一个管更大、一个管更小），**比"跑两趟分别求最大和最小"省一半循环**：
   ```rapid
   IF a{i}>vmax THEN vmax:=a{i}; ENDIF
   IF a{i}<vmin THEN vmin:=a{i}; ENDIF
   ```

## 五、与 0915 的衔接：擂台法的"升级"

这道题本质上是 **0915「求三个数最小值」的升级版**：

| | 0915 求三个数最小值 | **0916 求 8 个数最值差** |
|---|---|---|
| 数据形式 | 3 个**独立变量** `num1/num2/num3` | **1 个数组** `a{8}` |
| 比较方式 | 2 条独立 `IF`（手写） | **循环内 2 条 `IF`**（自动重复） |
| 扩展性 | 加一个数要加一段代码 | **改数组维度 + 循环上限即可** |
| 最值个数 | 只求最小 | **同时求最大和最小** |

> **核心认识**：**擂台法 + 循环 = 求任意多个数的最值**。数组让"数据可以批量存放"，循环让"比较可以自动重复"——**两者配合才能处理"数量未知/较多"的场景**。这是从"写死几个变量"到"处理一批数据"的关键一步。

## 七、一个额外观察：`ArrayEx` 是独立模块，没有 `main`

本题的 `ArrayEx` 是一个**独立的模块**（不是塞在 `Module1` 里），里面**只有 `max_min_diff` 一个例行程序、没有 `main`**。程序能跑，是因为把**程序指针（PP）直接设到了 `max_min_diff`**。

**这能成立的前提**：它**无参数**。手册/前日经验都确认了那条硬规则：

> **带参数的例程 / 函数不能设 PP**（会报 `C004900F : Given routine is not a legal entry point`）。

> **实用经验**：**想快速单测某个练习，就把它写成"无参例程"，直接设 PP 运行**，不必非要挂到 `main` 上。

## 八、要点串记

- **RAPID 数组从 1 开始计数**：`a{1}`~`a{8}`，**没有 `a{0}`**；循环写 `FOR i FROM 1 TO 8`。
- **声明看维度**（`VAR num a{8};`），**索引可以是变量**（`a{i}`），所以循环能统一处理。
- **读入 + 求值分两趟循环**：第一趟存数据，第二趟算结果。
- **擂台法求最值**：擂主取 `a{1}`，**从 `a{2}` 开始挑战**，两个 `IF` 同时维护最大和最小。
- **擂台法 + 循环 = 处理任意多个数**，比手写固定变量可扩展得多。
- **独立无参例程可以直接设 PP**，适合快速单测。
