# 2026-09-16 · WHILE 循环练习：用户登录系统

> **来源**：实操（RobotStudio 6.08 虚拟控制器 `260913System1`，模块 `LoginEx`）+ 官方手册《RAPID 语言内核技术参考手册》（**While 语句**、**Exit 语句**）。
> **练习要求**：使用 WHILE 语句编写**用户登录系统**——选择用户，输入正确密码后**显示欢迎用户**；**如果登录错误次数超过三次，则无法登录，显示 "NG"**。
> **本日成果**：第一次使用 **WHILE 循环**（此前只学过定次的 FOR），并**排掉了一个危险陷阱**——`EXIT` 不是"跳出循环"而是"终止整个任务"。

| 用户 | 密码 |
|------|------|
| user1 | 10 |
| user2 | 20 |
| user3 | 30 |

## 一、程序原文（控制器实际代码，模块 `LoginEx`）

```rapid
MODULE LoginEx
    PROC login()
        VAR num pwd{3};
        VAR num usr;
        VAR num input;
        VAR num tries;
        VAR bool ok;
        VAR num key;
        pwd{1}:=10;
        pwd{2}:=20;
        pwd{3}:=30;
        TPErase;
        TPReadFK usr,"Select user","user1","user2","user3","","";
        ok:=FALSE;
        tries:=0;
        WHILE ok=FALSE AND tries<3 DO
            TPReadNum input,"Password?";
            IF input=pwd{usr} THEN
                ok:=TRUE;
            ELSE
                tries:=tries+1;
            ENDIF
        ENDWHILE
        IF ok THEN
            TPWrite "Welcome user";
        ELSE
            TPWrite "NG";
        ENDIF
        TPReadFK key,"Done. Press OK to finish","","","","OK","";
    ENDPROC
ENDMODULE
```

## 二、★ WHILE 语法与"与 FOR 的分工"

**手册定义**（《RAPID 语言内核技术参考手册》→ 语句 → **While 语句**）：

```
<while statement> ::= WHILE <conditional expression> DO <statement list> ENDWHILE
```

> **"只要指定的条件表达式求值为真，那么，while 语句将重复对语句表进行求值。"**
> **"将在每一新循环前，对条件表达式进行求值和核实。"**
> **"只要条件表达式求值为假，那么将继续执行后续语句。"**

**注意最后那句**："**在每一新循环前**"对条件求值——这是 WHILE 和 FOR 的**根本区别**：

| | **FOR** | **WHILE** |
|---|---|---|
| 循环次数 | **开局定死**（手册：`FROM/TO/STEP` "只求值一次"） | **每轮重新判断**（可中途改变） |
| 退出方式 | 计数到上限自动退出 | **条件变假就退出** |
| 适用 | 次数**已知**（如"读 8 个数"） | 次数**不确定**（如"输入正确密码为止"） |

**本题为什么用 WHILE**：**不知道用户要试几次密码**——可能一次就对，也可能错三次。用 FOR 无法表达"对了就提前退出"。

## 三、★ 陷阱：`EXIT` **不是**"跳出循环"，而是"终止整个任务"

初学者最容易想到的写法是"循环里用 `EXIT` 跳出"。**这是个大坑。**

手册（→ 语句 → **Exit 语句**）原文：

> **"exit 语句用于立即终止任务的执行。"**
> **"不像从任务的入口程序返回，利用 exit 语句进行任务终止，还将禁止系统自动重启任务的尝试。"**

**后果很严重**：
1. 它会**终止整个任务**，不是跳出循环；
2. 循环后面的 `TPWrite "NG"`**根本执行不到**；
3. 还**禁止系统自动重启该任务**。

**正确做法：用条件变量控制循环**（本程序的写法）：

```rapid
ok:=FALSE;                      ← ① 先假设"没登录成功"
WHILE ok=FALSE AND tries<3 DO   ← ② 条件不满足就退出
    ...
    IF 密码正确 THEN
        ok:=TRUE;               ← ③ 改条件变量 → 下一轮判断时自然退出
    ENDIF
ENDWHILE
```

**核心思路**：**不去"跳"出来，而是"让条件变假"**。循环体负责改变状态，条件负责判断是否继续。

## 四、三个设计要点

### 1. 循环条件用"两个条件的 `AND`"

```rapid
WHILE ok=FALSE AND tries<3 DO
```

| 条件 | 含义 |
|---|---|
| `ok=FALSE` | 还**没**登录成功 |
| `tries<3` | 尝试次数**还没用尽** |

**两个都满足才继续**，任一不满足就退出——正好覆盖"成功"和"试错超限"两种结局，退出后统一判断。

> ⚠️ **这里我特意写成 `ok=FALSE` 而不是 `NOT ok`**：手册的表达式语法是
> `<expr> ::= [NOT] <logical term> { (OR | XOR) <logical term> }`，
> **`NOT` 与 `AND` 存在优先级歧义**（`NOT a AND b` 可能被解析成 `NOT(a AND b)`）。
> 用 `ok=FALSE` **语义明确、无歧义**。

### 2. 用数组存密码（复用同日学的数组）

```rapid
VAR num pwd{3};
pwd{1}:=10;   pwd{2}:=20;   pwd{3}:=30;
...
IF input=pwd{usr} THEN          ← usr 就是用户编号（1/2/3）
```

`TPReadFK` 的**返回值 = 按了第几个键**（手册："根据按下的键，返回数值 1..5 的变量"），所以：
- 按 `user1` → `usr=1` → `pwd{1}=10`
- 按 `user2` → `usr=2` → `pwd{2}=20`

**`pwd{usr}` 一次就取到对应密码** —— 如果用独立变量（`pwd1/pwd2/pwd3`），就得写三段 `IF usr=1 THEN ... ELSEIF usr=2 THEN ...` 来判断。**这就是"数组 + 索引"的便利。**

> 注意：数组索引从 **1** 开始（0916 数组练习学到的），而 `TPReadFK` 返回值也是 1~5，**正好对得上**，不用做 ±1 换算。

### 3. 结局统一判断（循环外一次 `IF`）

```rapid
IF ok THEN
    TPWrite "Welcome user";
ELSE
    TPWrite "NG";
ENDIF
```

**不用在循环里区分"是成功还是超次数"** —— 循环只负责"改状态"（改 `ok`、加 `tries`），**收尾时看 `ok` 一次性分流**。逻辑更清晰。

## 五、一个边界问题（可选择加防护）

如果用户按了 `""` 空键位（第 4 或 5 个键），`usr` 会是 **4 或 5**，此时 `pwd{usr}` 就**越界**了（数组只有 3 个元素）。

正常操作不会按到，但**要知道有这个边界**。要加防护可以补一句：

```rapid
TPReadFK usr,"Select user","user1","user2","user3","","";
IF usr>3 THEN usr:=1; ENDIF      ← 越界就强制回 user1
```

| 选 `user2`，输入 `20` | `Welcome user` ✅ |
| 选 `user1`，输错 3 次 | `NG` ✅ |

## 七、要点串记

- **WHILE 语法**：`WHILE <条件> DO ... ENDWHILE`，**每轮重新判断条件**。
- **FOR vs WHILE**：**次数已知用 FOR，次数不确定用 WHILE**。
- **★ `EXIT` 不是"跳出循环"** —— 它**终止整个任务**，还会禁止自动重启。**要用条件变量控制退出。**
- **循环条件可用多个条件的 `AND`**（如"未成功 AND 未超次"），覆盖多种退出情形。
- **优先用 `a=FALSE` 而非 `NOT a`**，避免 `NOT` 与 `AND` 的优先级歧义。
- **数组 + 索引替代多段 IF**：`pwd{usr}` 比 `IF usr=1 … ELSEIF usr=2 …` 简洁得多。
- **循环改状态、循环外统一判断**，逻辑更清晰。
