## 这是什么

十天实习分成两个阶段，两段正好是工业自动化的"眼睛"和"手"：

| 阶段 | 时间 | 主题 | 软件平台 |
|------|------|------|----------|
| **① 机器视觉实训** | 09-07 ~ 09-11（5 天） | 工业机器视觉：定位、测量、缺陷检测、识别分类、通信 | 海康 VisionMaster 4.3.0 + MVS 相机 |
| **② 机器人实训** | 09-13 ~ 09-17（5 天） | ABB 工业机器人：建站、示教、离线编程、RAPID 编程 | ABB RobotStudio 6.08 + 虚拟控制器 |

**学到的核心技术主线**：

```
机器视觉   定位标定 → 脚本与数据格式化 → 测量与通信 → 缺陷检测 → 循环与分类计数
机器人     环境建站 → 手动操纵/示教 → 工具与工件坐标系 → RAPID 运动指令 → 编程（分支/循环/数组）
```

两段笔记里都记了大量**踩坑与排错经验**（比如 RAPID 不能写中文、视觉循环的索引 Bug、坐标系统一性），
这些是课本上没有、只有动手才会遇到的内容，也是这份档案最值得看的部分。

## 配合 AI 助手使用

这份仓库除了给人看，也是**给 AI 助手看的**——根目录有一份 [`AGENTS.md`](AGENTS.md)，
是按"AI 能读懂"的格式写的交接说明：内容怎么组织、哪些地方有坑、术语什么含义、哪条结论出自哪本手册。

**用法**：把整个文件夹（或仓库地址）交给你的 AI 助手，让它先读 `AGENTS.md`，然后直接提问。比如：

> "读 AGENTS.md，然后帮我讲讲机器人实训里 `Offs` 是怎么用的，把相关笔记找出来。"

AI 会顺着索引去翻对应笔记，而不是靠猜。你也可以让它对照笔记帮你**复现练习**、**解释报错**、**按你的问题定位到具体某篇**。

> 对 AI 的协作约定（比如"学习记录随时写、日志要等用户发话"）也都写在 `AGENTS.md` 里，所以它不会自作主张改你的东西。

## 一些值得记住的坑（先看一眼，能省不少时间）

| 领域 | 坑 | 结论 |
|------|-----|------|
| RAPID | 代码里写中文 | 字符串和注释都会变 `?`（ISO 8859-1 字符集），**代码一律用英文** |
| RAPID | 两个存储位置 | 站点与控制器各存一份，**改代码→"同步到工作站"；改图形→"同步到 RAPID"**，方向反了旧版会覆盖新版 |
| RAPID | 数组索引 | **从 1 开始**，没有 `a{0}` |
| RAPID | `EXIT` | 是"终止整个任务"，**不是跳出循环**；跳出循环要用条件变量 |
| RAPID | PPT 里的 `<SMT>` | 那是**占位符**不是代码，照抄会报错，且**报错是全任务级的** |
| 视觉 | 循环索引失效 | 订阅参数时**要手动选变量类型**，否则默认值带中文会导致索引失效 |
| 视觉 | 变量计算初始化开关 | 累计计数要**关**（用上次结果），每轮重算要**开** |
| 视觉 | 分支模块 | 只认 `int`；收到字符串要先用脚本转成 `int` |
| 通用 | 坐标系一致性 | 目标点与运动指令必须引用**同一个工作对象**，否则目标点不可达 |
