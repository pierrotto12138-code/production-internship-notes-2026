## 摘要

本次实习围绕**工业视觉的"定位"与"标定"**两大核心展开。以"01-工业视觉工装板产品定位项目"为载体，使用 VisionMaster 搭建"模板匹配 + 位置修正 + 直线/角点提取 + 中心点求取"的定位流程，实现了在工件位置、角度不稳定的情况下稳定输出工件中心点；随后学习了 **N 点标定**，掌握"像素坐标 ↔ 物理坐标"的换算方法，为机械手抓取等运动机构引导奠定基础。

## 一、项目背景与目标

工业视觉中，**定位是视觉检测的骨架核心**：任何"判断"（测量、缺陷检测、识别）之前，都要先"找到东西在哪、什么角度"。

本项目针对**工装板**工件，目标是在工件位置/角度不稳定的前提下，稳定输出**工件的中心点坐标**。工件在画面里放歪、放偏都没有关系——关键在于测量的是"工件自身的几何关系"，而不是"工件在画面里的绝对位置"。

### 2.3 核心认知：线/点定位与模板是"相对定位"

本次最关键的认识是：**线定位与点定位，并不要求强制包在"快速匹配"模板里，而是和模板形成了"相对定位"关系。**

- **模板匹配**只需要定位一个"有辨识度的特征"（如工装板主体），用于**建立参考系 / 局部坐标系**。
- **位置修正**模块利用匹配结果，把基准点平移到/旋转到运行点，让后续测量、查找模块**始终作用在工件上**，而不是固定在画面坐标。
- 于是**直线查找、边缘交点所在的搜索区域会自动跟随工件移动、旋转**。

这正是工业上工件可以随意摆放、传输带乱转，检测依然稳定的原因——**测量的是"工件自己的几何关系"（夹角、中心、边距），而不是"工件在画面里的坐标"**。

> 一句话主线：**定位管参考系，测量管几何关系，两者靠"位置修正"串联。**

## 三、N 点标定：把像素换算成物理坐标

定位输出的是**像素坐标**；业务需要的是**毫米**。标定就是建立"像素 ↔ 物理尺寸"的换算关系，为机械手抓取等运动机构引导做铺垫。

### 3.1 平台布设：黑白格子纸

**推荐在平台上放置黑白格子纸（黑白棋盘格），单格尺寸按 30mm × 30mm。** 作为**已知真实物理尺寸的参照物**，配合机械手移动到若干已知物理坐标点，建立「像素坐标 ↔ 物理坐标」换算关系，用于**手眼标定 / 机械手抓取定位**。

### 3.2 标定操作流程

1. **在黑白格子的交界处（格子角点）做匹配**——交界点是 30mm 格子中最明确、最稳定的特征，边缘梯度最清晰。
2. **对选中的每个点用"高精度匹配"**——精度优先、特征清晰；对比"快速匹配"（速度优先）。标定误差会被后续测量放大，必须锁准。
3. **每成功选中一个点，记录一次该点的 X/Y 像素坐标**。
4. 与机械手已知物理坐标配对，建立「像素坐标↔物理坐标」转换。

### 3.3 关键界面：ROI 固定搜索区域

进入快速匹配「基本参数」→「ROI区域」：
- **ROI区域类型**：图形类型
- **ROI创建**：绘制
- **形状**：矩形（另有多边形/圆环）
- 在图像上**拖画矩形框住固定区域**，模板匹配只在框内搜索，框外不匹配。

> 作用：目标只在板子局部时，设 ROI 能**排除干扰、提速、防误检**。配套"最大匹配个数"（运行参数）可在固定区域内一次找多个目标。

### 3.4 点集对文件（txt）6列含义

以第一行 `1  925.611  757.208  130.17  86.8  0.000` 为例：

| 列 | 含义 |
|----|------|
| 第1列 | 点序号（1~9，九点标定） |
| 第2列 | **图像坐标X**（像素） |
| 第3列 | **图像坐标Y**（像素） |
| 第4列 | **物理坐标X**（mm，机械手实际位置） |
| 第5列 | **物理坐标Y**（mm） |
| 第6列 | **物理角度**（9点纯平移标定为0） |

> **第2、3列（图像坐标X/Y）与第4、5列（物理坐标X/Y）一一配对**，构成一个「像素↔物理」点对，是建立转换关系的两组数据（公式 `Pw = H·Pi`，Pi、Pw 均为2维坐标点）。**第6列（物理角度）是附加的旋转信息**，9点纯平移标定恒为0，不参与坐标配对。
> **物理点来源**：① 模块自动生成（推荐，用"物理坐标系参数"按网格算，界面不显示、不用手填）；② 接收通信数据 / 手动导入 txt。
> **无真实机械手** → 用软件自动生成物理点即可；**配真实机械手** → 第4、5列（物理坐标X/Y）必须与实际到达位置一致。
> N≥4；**9点标定**（共轴9次平移）、**12点标定**（不共轴9平移+3旋转）。

## 四、今日收获与小结

### 4.1 收获

1. **定位**：理解模板匹配建立参考系、位置修正带动下游、测量工件自身几何关系——"相对定位"是工业视觉稳定的关键。
2. **标定**：黑白格子 30mm 为参考 → 高精度匹配在格子交界处逐点定位 → 记录 N 组(像素,物理)点对 → 得像素精度。理解 9点/12点、N≥4、物理点两种来源。
3. **ROI 固定区域**：模板只在框内搜索，排除干扰、提速、防误检，为后续"多目标"检测打下基础。

### 4.2 存在的问题与改进方向

1. 当前输出单位是**像素**；如需输出**毫米**，后续需加**标定**，把像素换算成真实物理尺寸。
2. 若工件正反、种类变化，模板匹配得分会下降，需考虑**多模板**或换用**高精度匹配 / 图形定位**。
3. 下一步可将中心点坐标经**通信模块**（TCP/UDP/串口）传给上位机，用于引导后续动作。
4. 进入 **PCB 板质量检测（项目2）**，复用"ROI固定区域 + 最大匹配个数"做多目标识别。
