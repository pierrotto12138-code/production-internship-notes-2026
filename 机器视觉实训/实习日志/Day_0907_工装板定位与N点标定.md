## 二、工装板产品定位（当日第一部分）

流程链（12→23）：图像源 → 快速匹配 → 位置修正 → 四条直线 / 四个角点 → 中心点。

**核心认知——线/点定位与模板是"相对定位"**：

* **模板匹配**只需定位一个有辨识度的特征（工装板主体），用于**建立参考系 / 局部坐标系**。
* **位置修正**利用匹配结果，把基准点平移到/旋转到运行点，让后续模块**始终作用在工件上**，而非固定画面坐标。
* 于是直线查找、角点求交的搜索区域会自动跟随工件移动/旋转。

> 一句话主线：**定位管参考系，测量管几何关系，两者靠"位置修正"串联。** 测量的是"工件自身的几何关系"（夹角、中心、边距），不是"工件在画面里的坐标"。这就是工件随意摆放、传输带乱转时检测仍稳定的原因。详见 Day1 报告。

## 三、N点标定：黑白格子纸 + 格子交界处匹配（当日第二部分）

**要点（细节见两篇学习记录）**：

1. **布台**：平台上放黑白格子纸（单格 30mm × 30mm），作为已知物理尺寸的参照物。
2. **选点**：在**格子交界处（角点）**做**高精度匹配**，逐点记录像素 X/Y——交界点边缘梯度最清晰，比整格/格心稳。
3. **配对**：与机械手已知物理坐标一一对应，建立「像素 ↔ 物理」转换（公式 `Pw = H·Pi`）。
4. **点集对文件 6 列**：点序号、图像 X/Y、物理 X/Y、物理角度；N≥4，常用 9 点（共轴平移）/ 12 点（9 平移 + 3 旋转）。
5. **物理点来源**：模块按网格自动生成（无真机时用），或接收通信数据 / 手动导入 txt。
6. **ROI 固定搜索区域**：匹配只在框内搜索，排除干扰、提速、防误检；配合"最大匹配个数"可一次找多个目标。

> 细节见 [2026-09-07_N点标定_黑白格子纸](../学习记录/2026-09-07_N点标定_黑白格子纸.md) 与 [2026-09-07_高精度匹配九点逐个标定](../学习记录/2026-09-07_高精度匹配九点逐个标定.md)（含界面截图与逐项解读）。

## 四、遇到的问题

1. **中心点输出仍是像素坐标**：要换算成毫米、给机械手用，必须再做标定——当天下午的 N 点标定正是补这一步。
2. **模板匹配对工件变化敏感**：工件正反、种类一变，匹配得分会下降；后续可考虑**多模板**或换用**高精度匹配 / 图形定位**。
3. **没有真实机械手**：物理点只能由软件按网格生成，标定结果无法与真机位置比对。

## 五、当日收获与小结

1. **定位**：理解了模板匹配建立参考系、位置修正带动下游、测量工件自身几何关系——"相对定位"是工业视觉稳定的关键。
2. **标定**：黑白格子 30mm 为参考 → 高精度匹配在格子交界处逐点定位 → 记录 N 组(像素,物理)点对 → 得像素精度。理解了 9点/12点、N≥4、物理点两种来源。
3. **ROI 固定区域**：模板只在框内搜索，排除干扰、提速、防误检，为后续"多目标"检测打下基础。
