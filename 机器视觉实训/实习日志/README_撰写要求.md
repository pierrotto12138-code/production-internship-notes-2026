# 实习日志 · 撰写要求（来自《实习手册》填写说明）

> ⚠️ **免责声明**：本仓库全部内容为基于个人学习记录**由 AI 自主整合**的版本，**未经人工优化**，仅供学习内容参考；如照搬全抄造成课程成绩损失，概不负责。

> 依据：实习手册《填写说明》。用于指导本目录下所有实习日记与实习报告的撰写与优化。

## 一、实习日记（每天做）

**要求**：参加实习的学生必须每天对实习情况做日记。实习日记应**准确地反映实习当天的情况**，包括：

- **实习时间**
- **实习地点**
- **实习方式**
- **实习内容**
- **遇到的问题**
- **收获心得** 等

## 二、实习报告（实习结束前写）

**要求**：实习结束之前，学生必须认真撰写实习报告。实习报告应包含本次实习的：

- **基本情况介绍**
- **实习目的**
- **实习内容**
- **实习的收获**（学到的知识、掌握的技能、心得体会等）

> 撰写报告的目的：通过撰写报告，**系统回顾和总结实习的全过程**，将实践性教学的感性认识升华到一定的**理论高度**，从而提高实习教学效果。

## 三、报告质量（评分依据）

- 实习报告的撰写应符合**实习大纲**的要求。
- 实习报告的质量反映了实习的质量，它是**实习成绩评定的主要依据之一**。
- 实习报告需经**指导教师审阅并签署意见**。

## 四、实习手册组成与形式

- 实习手册包含**实习日记**和**实习报告**两部分。
- **要求手写**，条理清晰、内容详实、层次清楚、字迹工整。

## 五、归档

实习结束后，学生将实习手册上交**开课学院**存档。

- 实习报告（综合）：`YYYYMMDD专业生产实习报告.md`（本仓库仅存 0907 阶段稿；完整报告 docx/pdf 含姓名学号，**不随仓库/分享包提供**）
