# 2026-09-09 · 焊点检测 与 边缘对模型缺陷检测

> **来源**：实操（VisionMaster 4.3.0）。关联《第5章_缺陷检测》《第7章_图像处理》《第3章_定位查找》《第11章_逻辑脚本》。
> **两个案例**：① 焊点检测（功率模块焊点） ② 边缘对模型缺陷检测（塑料片等）。

## 一、焊点检测

### 1. 案例对象
功率模块/电机控制器（PCB板）上的**焊点**。检测焊点是否合格（缺焊/少锡/连锡/多锡等）。

### 2. 我的流程
```
41焊点检测 → 42图像滤波1(取反) → 43快速匹配1 → 44位置修正1
   → 45上焊点 / 46UVW焊点 → 47条件检测1
```

### 3. 设计思路（关键）
**先滤波取反 → 分别匹配上下两处焊点 → 以坏的为基准 → 发现坏工件才拉高电平。**

- **42图像滤波1（取反）**：图像反色，让焊点/背景对比更适合检测。
- **43快速匹配1 + 44位置修正1**：定位焊点区域，建立参考系。
- **45上焊点 / 46UVW焊点**：分别检测两处焊点（一处在上，一处是UVW区域）。
- **47条件检测1**：综合两处焊点结果判定。

### 4. 条件检测配置（截图）
- **判断方式**：全部（AND，全部满足才OK）
- **int0**：`45上焊点.积分`，有效值范围 **1~2**
- **int1**：`46UVW焊点.积分`，有效值范围 **1~2**
- → 两处焊点的"积分"值都在 1~2 之间 → OK；否则 NG。

> "积分"= 焊点检测模块输出的度量值（焊锡量/面积/灰度积分）。范围 1~2 是"正常焊点"的基准区间。

### 5. 以坏为基准的逻辑
- 以坏焊点的积分值作阈值基准，"积分不在正常范围(1~2)" → NG → 触发高电平（报警/剔除）。
- 正常焊点积分落在 1~2 → OK。

## 二、边缘对模型缺陷检测

### 1. 案例对象
塑料片（边缘对之间的缺陷检测）。检测两边缘之间的**宽度/位置偏移/气泡**等。

### 2. 我配置的参数（截图）
**通用参数**：
| 参数 | 配置 |
|------|------|
| 边缘查找类型 | 最接近边缘对 |
| 卡尺高度 | 50 |
| 卡尺宽度 | 5 |
| 理想宽度 | 30 |
| 边缘阈值 | 25 |
| 边缘0极性 | 任意极性 |
| 边缘1极性 | 任意极性 |
| 中心点使能 | 关 |

**缺陷参数**（另一处塑料片）：
| 参数 | 配置 |
|------|------|
| 缺陷极性 | 轨迹两侧缺陷 |
| 缺陷距离阈值 | 20 |
| 缺陷尺寸使能 | 关 |
| 缺陷面积使能 | 关 |

### 3. 关键参数量
- **边缘查找类型**：最接近边缘对 —— 找离卡尺中心最近的边缘对。
- **理想宽度**：期望的边缘对宽度（如30），实际宽度偏离它越大越可能是缺陷。
- **边缘0/1极性**：两条边的明暗方向。
- **缺陷极性**：轨迹两侧/左/右。
- **缺陷距离阈值**：边缘点距拟合直线的距离阈值，超了才判缺陷。

## 三、缺陷检测家族速记（第5章）

| 类型 | 检测什么 |
|------|---------|
| 边缘组合缺陷检测 | 单条边缘上的缺陷 |
| 边缘对组合/模型缺陷检测 | 两条边缘之间的缺陷（宽度/位置偏移/阶梯/断裂/气泡）|
| 圆弧边缘缺陷检测 | 圆弧边缘上的缺陷 |
| 直线边缘缺陷检测 | 直线边缘上的缺陷 |
| 圆弧对缺陷检测 | 两圆弧之间的缺陷 |
| 直线对缺陷检测 | 两直线之间的缺陷 |
| 字符缺陷检测 | 字符缺笔画/糊字 |
| 异常检测 | 无缺陷样本 vs 待测（AI类）|

> **选型口诀**：缺陷在**边上**→边缘类；缺陷在**两条边之间**→边缘对/直线对/圆弧对；缺陷在**表面**→表面滤波+BLOB；**字符**→字符缺陷检测。

## 四、要点串记

- **焊点检测**：滤波取反 → 匹配定位 → 检测焊点积分 → 条件检测比对范围（以坏为基准，坏件触发高电平）。
- **边缘对模型缺陷检测**：卡尺找边缘对 → 比对理想宽度 → 缺陷距离阈值判缺陷。
- **共同点**：都靠**卡尺找边缘/边缘对** + **阈值判定**；都需要**定位（匹配+位置修正）**做前置参考系。
