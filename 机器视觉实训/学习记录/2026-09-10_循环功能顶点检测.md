# 2026-09-10 · 循环功能（顶点检测 + Group循环 + 圆拟合）

> **来源**：实操（VisionMaster 4.3.0）+ 案例《练习图片/循环功能》（说明：使用【循环】工具找到所有顶点）+ 官方帮助《顶点检测》《Group》。关联《第3章_定位查找》《第11章_逻辑脚本》。
> **案例**：用**顶点检测 + Group循环**找星形零件的**全部顶点**，再**圆拟合**。**已完成。**

## 一、案例目的

使用 **【循环】工具找到所有顶点**。工件为星形零件（外缘约12个尖角，均匀分布）。

## 二、核心难点：顶点检测一次只出一个顶点

- **顶点检测**：在 ROI 内查找一个顶点，输出**顶点(X,Y)**、顶点分数、顶点极性、顶点距离。
- **一个顶点检测模块，一次只输出一个顶点** → 星形有约12个尖角，**必须用 Group+循环**逐个检测。

## 三、解决方案：Group循环 + ROI数组索引（关键机制）

### 1. 最终流程
```
16图像源1 → 17快速匹配1 → 组合模块1(Group循环) → 20圆拟合1
```

![循环完成-圆拟合](../../配图/Day1_images/image-0910_loop_done.png)

### 2. Group 输入设置（关键）
![Group输入设置](../../配图/Day1_images/image-0910_group_input.png)

| 参数名称 | 类型 | 订阅关系 |
|---------|------|---------|
| `ImageData` | IMAGE | `16图像源1.图像[]` |
| `InputROI` | BOX | `17快速匹配1.匹配框[]` |

> - **ImageData**：传入图像。
> - **InputROI**：传入**ROI数组**（匹配框数组）。这是循环的基础——**数组里有 N 个ROI**。

### 3. 顶点检测的 ROI 绑定索引（**核心**）
顶点检测的 ROI 区域填：
```
组合模块1.InputROI[组合模块1.循环索引]
```
- **`循环索引`**：Group 循环自动递增的变量（0,1,2,...）。
- 每轮循环，ROI 取数组里第 N 个 ROI → 逐个检测每个尖角。
- **原来写死 `InputROI[2]`（固定索引）→ 永远只看同一个尖角，只能出一个顶点！** 改成 `InputROI[循环索引]` 才能逐个遍历。

### 4. 顶点检测运行参数（本次）
![顶点运行参数](../../配图/Day1_images/image-0910_vertex_runparam.png)

| 参数 | 配置 |
|------|------|
| 滤波尺寸 | 3 |
| 边缘阈值 | 40 |
| 边缘极性 | 任意极性 |
| 扫描宽度 | 2 |

### 5. Group 循环设置
| 参数 | 设置 |
|------|------|
| 循环使能 | 开启 |
| 循环起始值 | 0 |
| 循环结束值 | 12（订阅值；结束值−起始值=循环次数）|
| 循环间隔(ms) | 按需 |

> Group 循环**最多显示40次渲染结果**。

### 6. 汇总与输出
- Group 内部用 **图形收集 / 数据集合** 收集每次循环的顶点 → 得到全部顶点集合。
- Group 的**输出设置必须配**（否则 Group 显示模块状态0，内部OK也算0）。

### 7. 圆拟合（最终）
把全部顶点经 **20圆拟合1** 拟合成圆：
- 结果：圆心 (645.6332, 494.6814)、圆半径 442.7244、拟合状态 1、拟合误差 2.328298、匹配点数 8。

## 四、★重要 Bug（本次踩坑）

**错误来源**：默认选择（订阅参数）后，**默认值带中文字符**，产生 bug，导致索引失效。

**解决办法**：
- **手动选择变量类型后，再进行索引**（即：先把该参数的类型显式选好，再做 `[循环索引]` 索引），问题消失。

> 复现特征：用 `InputROI[循环索引]` 只出1个顶点或报错 → 检查参数类型是否被默认的中文值污染，**手动重选类型**。

## 五、要点串记

- **顶点检测 = 单点检测**（一次一个顶点），找多个顶点必须**循环**。
- **Group 循环的核心**：`输入ROI数组[循环索引]` —— 用循环索引**逐页翻 ROI 数组**，逐个目标检测。
- **三要素对齐**：InputROI 数组元素个数 = 循环次数；循环起止值设对。
- **汇总**：图形收集/数据集合把逐次结果合成集合；**Group 输出设置必须配**。
- **踩坑**：默认参数值带中文字符会出 bug，**手动选类型后再索引**。
- **延伸**：顶点集合可再送**圆拟合**，得圆心/半径——"先找点、再拟合形状"是常见套路。
