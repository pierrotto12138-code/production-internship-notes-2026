# 2026-09-07 · N 点标定：黑白格子纸 + 格子交界处匹配

> **来源**：上课/实操口述要点 + 《VisionMaster知识库/第6章_标定.md》《第3章_定位查找.md》。涉及 N点标定、高精度匹配模块。

## 一、平台布设：黑白格子纸

- **N 点标定时，推荐在平台上放置黑白格子纸（黑白棋盘格），单格尺寸按 30mm × 30mm。**
- 用途：作为**已知真实物理尺寸的参照物**，配合机械手移动到若干已知物理坐标点，建立「像素坐标 ↔ 物理坐标」的换算关系，用于**手眼标定 / 机械手抓取定位**。
- 对应知识库要点：配合机械手抓取 → 用 **N点标定 / 平移旋转标定**；只测图像尺寸（无机械手）→ 用**标定板标定**。

## 二、标定操作流程（实操补充）

1. **在黑白格子的交界处（格子角点）做匹配**——把格子交界点作为定位特征点，而不是整格或格心。
2. **对选中的每个点用"高精度匹配"**：高精度匹配精度优先、特征清晰，适合作为标定点位的匹配方式（对比：快速匹配=速度快、特征清晰）。
3. **每成功选中一个点，就记录一次该点的 X/Y 像素坐标**。
4. 配合机械手移到已知物理坐标点，软件建立「像素坐标 ↔ 物理坐标」转换；之后相机测到某位置的像素坐标，就能换算回机械手要去的物理坐标。

## 三、要点串记

- **为什么选交界处**：黑白交界的角点是 30mm×30mm 格子中最明确、最稳定的特征，匹配定位最准；整格/格心容易受光照、模糊影响，交界点的边缘梯度最清晰。
- **为什么用高精度匹配**：标定要求点位尽量精准（一次标定误差会被后续所有测量放大），故用精度优先的高精度匹配逐个锁点，而非追求速度。
- **逐点记录 XY**：N 点标定的本质就是"采集 N 组「像素坐标 ↔ 物理坐标」对应点"，点的数量越多、分布越开，拟合出的像素精度越准。
- **何时需要标定**：配合机械手抓取/贴合 → 需要（N点标定）；只判有无缺陷 → 不需要；要报真实尺寸 → 需要（标定板标定）。
- **标定误差**：允许 0.1~0.5 之间；误差 >0.5 要重新标定（检查格子纸是否放平、光照是否均匀、特征点是否提取全）。
