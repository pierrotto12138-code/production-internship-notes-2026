# 2026-09-09 · 卡尺测量 与 圆环展开

> **来源**：实操（VisionMaster 4.3.0）+ 官方帮助《卡尺工具》《圆环展开》。关联《第3章_定位查找》《第7章_图像处理》《第9章_识别》。
> **两个任务**：① 卡尺-间距（测量） ② 圆环展开-字符识别。

## 一、卡尺工具（卡尺-间距任务）

### 1. 用途
卡尺工具主要用于**测量物体宽度、边缘特征位置、边缘对的位置和间距**。在图像 ROI 内做**快速且精确**的检测定位。常与图像源、模板匹配、位置修正组合：**模板匹配 + 位置修正做粗定位，卡尺工具做精定位**。

### 2. 算法流程（官方）
1. **输入ROI**：从前序模块获取 ROI，投影区域为任意角度的矩形。
2. **一维投影**：沿一个方向投影成一维数据。
3. **一维差分滤波**：增强边缘、抑制噪声（滤波核越大抗噪越强，但极值精度越差）。
4. **边缘极性**：从黑到白 / 从白到黑 / 任意。滤波后极值点转成**谷值（极小）和峰值（极大）**。
5. **插值得亚像素**：对极值点插值，得出亚像素精度边缘位置。
6. **评分选择**：按位置/间距/对比度/灰度等评分，取得分最高的结果。

### 3. 运行参数（本任务配置）
| 参数 | 配置 | 说明（官方） |
|------|------|------|
| **边缘模式** | 边缘对 | 单边缘：检边缘位置（定位/计数/有无）；边缘对：检**边缘间距**（测宽度） |
| **滤波尺寸** | 2 | 增强边缘抑噪，最小1；边缘模糊/噪声大时调大 |
| **边缘阈值** | 15 | 梯度阈值0~255；越大抗噪越强、边缘越少 |
| **边缘0极性** | 从白到黑 | 灰度突变方向 |
| **边缘1极性** | 从黑到白 | 边缘对模式下才有边缘1极性 |
| **边缘对宽度** | 40 | 期望边缘对间距（相对位置/间距评分基准）|
| **最大结果数** | 4 | 返回符合要求的边缘对个数上限 |
| **排序方式** | 分数降序 | 按得分排序 |

### 4. 输出结果（当前结果表）
| 边缘点0X/Y、边缘点1X/Y | 边缘0/1极性 | 测量宽度 | 分数 | 边缘状态 |
|------|------|------|------|------|

> 例：`453.8201 668.404 453.8201 690.4081  2  1  22.04417  0.5501043  1`（测量宽度=22.04，分数=0.55）。

### 5. 流程串联（卡尺-间距）
```
0图像源1 → 1高精度匹配 → 2位置修正
3卡尺工具1 / 4卡尺工具2 → 5直线查找1 / 6直线查找2 → 7线线测量1
```
> 卡尺工具的**匹配点/边缘点**可作为直线查找输入，最终用**线线测量**量夹角/距离。本任务线线测量输出：夹角 -0.00168、绝对距离 332.6013。

## 二、圆环展开（圆环展开-字符识别任务）

### 1. 用途
从特定起始角度将**圆环图像展开为矩形图像**，用于**消除圆环部件上字符因环状呈现导致的识别问题**。适用：圆环零部件检测、瓶口缺陷检测、圆环部件字符检测等。

> **为什么**：字符在圆环上呈弧形/弯曲，OCR 难识别；**先圆环展开摊平再识别**，识别率更高（《第9章 识别》预处理建议）。

### 2. 基本参数（本任务配置）
| 参数 | 配置 | 说明 |
|------|------|------|
| **图像输入** | 8图像源1.图像 | 前序图像源 |
| **ROI创建** | 绘制 | 画圆环ROI；另有"继承"沿用上游 |
| **形状** | 圆环(图上扇形/弧) | 在图上框出环形区域 |
| **位置修正** | 开启 | 勾选工具栏"位置修正"图标 |
| **选择方式** | 按信息 | 订阅位置修正信息（10位置修正1.位置修正信息）|
| **修正信息** | 10位置修正1.位置修正信息 | 让圆环ROI跟随工件移动/旋转 |

### 3. 关键输出
- **输出图像**：展开成的矩形图像（仅支持 HKA_IMG_MONO_08 单色8位格式）。
- 输出图像宽度/高度、像素格式（17301505=Mono8，35127316=RGB24）。
- **检测区域**、**圆弧ROI**（中心X/Y、内径、外径、起始角度、角度范围）。

### 4. 半径方向（官方）
- **由内向外**（从内径开始累加至外径）
- **由外向内**

> 后序一般接**几何变换**做方向转换；本任务接**字符识别**。

### 5. 本任务效果
```
8图像源1 → 9高精度匹配 → 10位置修正 → 11圆环展开1
```
圆环部件上的 `O8C-1246V`（环形字）经圆环展开后，摊平为一字排开、清晰可辨的矩形条，便于后续字符识别（OCR）读取。

## 三、通信收发 + 自动切图识别（NetAssist ↔ VisionMaster）

> **来源**：实操 + 官方帮助《分支模块》《分支字符》《脚本开放接口》、知识库《第11章_逻辑脚本》《第12章_通信》。
> **目标**：NetAssist 发 `1/2/3` → VisionMaster 自动加载对应图片（1.png/2.png/3.png）并跑对应识别（二维码/条码/字符识别）→ 结果回传 NetAssist。**已跑通（收到 209226200600... 二维码、RHEIN-KOSTER 字符）。**

### 1. 完整流程链
```
13接收数据1 → 16脚本1 → 17分支模块1 → 211 / 182 / 193（三个图像源）
   → 22二维码识别 / 23条码识别 / 24字符识别 → 25格式化1 → 26发送数据2
```

### 2. 关键设计（多图像源+分支，不依赖改路径，必成）
- **三个图像源**：211、182、193 各自固定加载 1.png / 2.png / 3.png。
- **脚本**：把接收到的字符串 "1"/"2"/"3" 转成 int `route`（1/2/3）。
- **分支模块**：按值索引认 int，条件输入绑脚本的 `route`，值1→图源211、值2→图源182、值3→图源193。
- 识别结果汇总到格式化，再发送回 NetAssist。

### 3. 脚本核心
输入 `recv`(string，绑接收数据)，输出 `route`(int)：
```csharp
string cmd = "";
GetStringValue("recv", ref cmd);   // 收到的 "1"/"2"/"3"
int route = 0;
if (cmd == "1")      route = 1;    // 二维码
else if (cmd == "2") route = 2;    // 条码
else if (cmd == "3") route = 3;    // 字符
else                 route = 0;
SetIntValue("route", route);
```

### 4. 通信连接（NetAssist 客户端 ↔ VM 服务器）
- NetAssist：TCP Server，本机 127.0.0.1:8080，点「打开」（监听）。
- VisionMaster：TCP服务器，本机IP 127.0.0.1，端口 8080。
- **客户端目标IP/端口 = 服务端本机IP/端口**（一致才能通，曾因不一致连不上）。

### 5. 关键认知
- **分支模块只认 int**：接收到的字符串需**用脚本转成 int** 再给分支模块。
- **分工**：脚本管"读/转"、分支管"路由"、图像源管"切图"。
- **通信排查点**：一服务端一客户端、IP/端口一致、接收数据绑对设备（服务端收客户端数据）。

## 四、要点串记（今日三大任务）

- **卡尺工具**：边缘对模式测**间距/宽度**；模板匹配+位置修正粗定位、卡尺精定位；`边缘阈值/滤波尺寸/对宽度`是核心调参项。
- **圆环展开**：把圆环**摊平**成矩形，解环形字符识别难题；**位置修正**保证ROI跟着工件转；输出是单色8位图。
- **通信切图**：接收→脚本(转int)→分支模块(按值选路)→多图像源→识别→格式化→发送；脚本管读/转、分支管路由、图像源管切图。
- **共同点**：都用 **ROI（绘制）+ 位置修正** 保证检测区域跟随工件（卡尺/圆环展开）。
