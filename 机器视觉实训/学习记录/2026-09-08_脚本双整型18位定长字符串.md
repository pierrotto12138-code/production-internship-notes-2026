# 2026-09-08 · 脚本模块：双整型 → 18位定长字符串（正负1位）

> **来源**：实操（VisionMaster 脚本模块，C#）。关联《第11章_逻辑脚本.md》，官方帮助《脚本》《格式化》。
> **目标**：输入 x、y 两个整型，输出 18 位定长字符串，结构 = 正负1位 + x数值8位 + 正负1位 + y数值8位。**已跑通（结果 +00013663-00002640）。**

## 一、需求与编码约定

- 输入：两个整型 `x`、`y`（来自变量计算模块）。
- 输出：**18 位字符串**，结构 `1+8+1+8 = 18`：

| 段 | 占位 | 示例（x=13663, y=-2640）|
|----|------|------|
| 符号x | 1 | `+` |
| x数值 | 8 | `00013663` |
| 符号y | 1 | `-` |
| y数值 | 8 | `00002640` |

- **注意两种编码约定**：
  - 初版用 `+/−` 字符（`x>=0?"+":"-"`）。
  - 老师要求用 **`1` 代表正、`0` 代表负**，符号仍占 **1 位**，总长仍为 **18**。

## 二、完整代码（+/- 占位版本，已跑通）

```csharp
public bool Process()
{
    int x = 0, y = 0;
    GetIntValue("x", ref x);
    GetIntValue("y", ref y);

    string xSign = x >= 0 ? "+" : "-";
    string ySign = y >= 0 ? "+" : "-";
    int absX = Math.Abs(x);
    int absY = Math.Abs(y);
    string xNum = absX.ToString("D8");   // 8位，左补0
    string yNum = absY.ToString("D8");

    string result = xSign + xNum + ySign + yNum;  // 长度18
    SetStringValue("out_str", result);
    return true;
}
```

## 三、关键点：int 补不了零 → 需要 string

**C# 特性：int 类型存不了前导零。** `13663` 存入 int 就是 `13663`，前面的零被丢弃；补零产生的是**字符串**。所以：

- 数值部分（x1/y1）要输出 **string**，用 `ToString("D8")` 补零到 8 位。
- 符号部分（label）可保持 int（`1`/`0`），占 1 位。

**方案对比：**

| 方案 | 变量 | 能否出18位 |
|------|------|-----------|
| ① 数值用 string | x1/y1 为 string，label 为 int | ✅ 脚本内直接补零 |
| ② 纯 int + 格式化 | 4 个都是 int | ⚠️ 取决于格式化能否"补零到定宽" |

> **结论**：若硬性要求"四个变量都是 int"，脚本内无法出 18 位（int 存不了前导零）。**要么数值转 string 在脚本补零；要么格式化模块支持"定宽补零"**。后者需核实格式化模块能力。

## 四、老师约定的"1正0负"版本（数值用 string 的最终版）

```csharp
public bool Process()
{
    int x = 0, y = 0;
    GetIntValue("x", ref x);
    GetIntValue("y", ref y);

    int x1_label = x >= 0 ? 1 : 0;          // 1=正，0=负
    int y1_label = y >= 0 ? 1 : 0;
    string x1 = Math.Abs(x).ToString("D8"); // 8位补0
    string y1 = Math.Abs(y).ToString("D8");

    SetIntValue("x1_label", x1_label);
    SetStringValue("x1", x1);
    SetIntValue("y1_label", y1_label);
    SetStringValue("y1", y1);
    return true;
}
```

结果（x=13663, y=-2640）：`x1_label:1; x1:00013663; y1_label:0; y1:00002640` → 格式化拼成 `100013663000002640`（18位）。

## 五、易踩的坑

1. **只贴 Process() 会报错**：脚本必须包在 `public partial class UserScript:ScriptMethods,IProcessMethods{...}` 里。报错 `应输入 class...` → 缺类外壳。
2. **int 补不了零**：数值必须 `string` + `ToString("D8")`；label 可 int。
3. **`Math.Abs(int.MinValue)` 溢出**：坐标远小于 2147483648，忽略。
4. **`ref` 必须带**：`GetIntValue("x", ref x)`，漏了读不到。
5. **符号位定长**：若老师约定符号占 2 位（"01"），总长变 20 位，需重构——但本任务明确**符号占1位、总长18**。

## 六、与格式化模块的配合

需求：**脚本只管"算出 4 个 int/string"，用什么拼交给格式化模块**。
- 脚本输出 `x1_label / x1 / y1_label / y1`。
- 格式化模块订阅这四个变量，用"插入文本 + 插入订阅 + 分隔符"拼成 18 位串。
