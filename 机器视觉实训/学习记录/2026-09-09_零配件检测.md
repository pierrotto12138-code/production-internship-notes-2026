# 2026-09-09 · 零配件检测（综合案例）

> **来源**：实操（VisionMaster 4.3.0）+ 案例说明《练习图片/零配件检测》。关联《第3章_定位查找》《第4章_测量》《第5章_缺陷检测》《第11章_逻辑脚本》。
> **案例**：零配件检测（焊锡与圆柱体位置关系 + 漏空）。综合运用定位/间距检测/变量计算/Blob/条件检测。**已完成，判定 OK。**

## 一、案例目的

检测**焊锡及焊锡以上部分不能超出下方圆柱体**，同时**焊锡与中间塑料板保持漏空**（有空隙）。

- 合格品：焊锡未超出圆柱体，焊锡与塑料板间漏空。
- 不合格品：焊锡超出圆柱体范围，或焊锡与塑料板粘连（无漏空）。

## 二、5 步流程

```
1. 快速特征匹配  → 对焊锡部分初定位
2. 间距检测      → 测焊锡两端距离、焊锡下方圆柱体距离
3. 变量计算      → 比较焊锡及以上是否超出圆柱体
4. Blob检测      → 检测焊锡和塑料板是否漏空
5. 条件检测      → 同时满足"变量计算>0 且 blob个数>3" → 工件合格
```

## 三、本项目搭建流程（本任务实际）

```
28图像源1 → 29快速匹配1 → 30位置修正1
31上间距 / 32下间距 → 34变量计算1 → 33条件检测1
                → 35BLOB分析(漏空检测)
```

## 四、关键配置

### 1. 变量计算：判断"上间距 > 下间距"（大才是对的）
- **表达式**：`<31上间距.测量宽度> > <32下间距.测量宽度>`
- **输出**：`var0`(float)，结果 = **1（上间距大，对）/ 0（假）**。
- **验证**：反向用 `<` 测试输出 0，确认判断正确。

> 踩坑：曾错用 `<31上间距.边缘个数>`（"边缘个数"不是间距），应选 **`.测量宽度`**。

### 2. Blob 分析：检测漏空
- 检测焊锡与塑料板间的连通域个数（漏空缝隙）。
- 合格品漏空块数 > 3；粘连则块数少 → NG。

### 3. 条件检测：综合判定
- 同时满足：**变量计算 var0>0（上间距大/未超出）且 blob个数>3（漏空）** → 工件合格（OK）。

## 五、结果

- 结果区显示 **模块状态1结果:OK**（合格判定生效）。
- 通过"上间距>下间距"（变量计算）+ "blob>3"（漏空）两个条件共同成立判合格。

## 六、要点串记

- **综合检测线**：定位(参考系) → 间距测量(量宽度) → 变量计算(数值比较/判断) → Blob(连通域/漏空) → 条件检测(多条件AND)。
- **变量计算做"比较"**：判断"上间距>下间距"这类比较，用 `>` 运算符，输出 1/0。
- **Blob 判断漏空**：连通域个数是判断"有没有空隙/有没有粘连"的有效手段。
- **条件检测做多条件联合**：多个指标同时满足才合格。
