# 2026-09-08 · 脚本模块入门：数量判定 OK/NG

> **来源**：实操（VisionMaster 脚本模块，C#）。关联《第11章_逻辑脚本.md》，官方帮助《脚本》《脚本开放接口》。
> **目标**：读入"检测数量"，为 4 时输出 OK，否则输出 NG。**已跑通。**

## 一、功能目标

- 输入量：快速匹配等前序模块的 **匹配个数**。
- 判定规则：数量 **==4** → 输出 **"OK"**；其他数量 → 输出 **"NG"**。
- 输出：一个字符串（string）变量，供下游格式化 / 数据显示 / 通信发送使用。

## 二、编辑前的配置（在脚本编辑窗口上方"输入/输出变量编辑区"）

| 类型 | 变量名 | 数据类型 | 绑定 |
|------|--------|---------|------|
| 输入变量 | `in0` | `int` | 绑定前序模块的「匹配个数」 |
| 输出变量 | `out0` | `string` | 供后置模块读取 |

> 变量名必须与代码里 `GetIntValue("in0",...)` / `SetStringValue("out0",...)` 中的名字**一字不差**。

## 三、完整代码（可复用）

```csharp
using System;
using System.Text;
using System.Windows.Forms;
using Script.Methods;

public partial class UserScript:ScriptMethods,IProcessMethods
{
    int processCount ;          // 成员变量：执行次数计数

    public void Init()          // 预编译/加载方案时只跑一次
    {
        processCount = 0;
    }

    public bool Process()       // 每次流程执行一次
    {
        // 1) 读入"检测数量"
        int count = 0;
        GetIntValue("in0", ref count);

        // 2) 数量为4 → OK，否则 → NG
        if (count == 4)
            SetStringValue("out0", "OK");
        else
            SetStringValue("out0", "NG");

        return true;            // 模块显示绿；OK/NG 通过 out0 字符串带出
    }
}
```

## 四、核心要点（读→判→写 三步链路）

脚本本质 = **读取（Get）→ 运算/判断（if）→ 写入（Set）**，这是所有程序骨架。

1. **读** `GetIntValue("in0", ref count)`：
   - `"in0"` = 输入变量名，须与编辑区一致。
   - `ref count` = **引用传递**，把读到的值填回 `count`。**漏掉 `ref` 值读不回来**，count 恒为 0。
   - 读数量用 `GetIntValue`；读坐标(浮点)用 `GetFloatValue`；读写文字用 `Get/SetStringValue`。**类型与接口必须配套**。

2. **判** `if (count == 4)`：`==` 是判断相等（两个等号），赋值才是 `=`（一个）。别混。

3. **写** `SetStringValue("out0", "OK"/"NG")`：把结果写进 `out0` 字符串，下游模块可读。

4. **`return true`**：决定脚本模块本身显示**绿/红**。要"用字符串输出OK/NG"保持 `true`（模块不报错）；若想让"数量≠4 时模块变红/流程中断"，可改 `return count == 4;`（两种方式二选一）。

## 五、易踩的坑

| 坑 | 原因 | 后果 |
|----|------|------|
| 变量名不一致 | `"in0"/"out0"` 与编辑区定义不同 | 读不到/写不进，但**不报错**（最阴） |
| 漏写 `ref` | C# 引用传递 | count 永远是 0 |
| 类型不配套 | 读整型用 `GetFloatValue` 等 | 结果错误 |
| `==` 写成 `=` | 判断写成赋值 | 逻辑错误、变量被改写 |
| 逻辑放错方法 | 把"每张图判定"错放 `Init()` | 只执行一次，不随流程走 |

- **独立判定**（每张图重新算）：Process 里每次重算即可（本案例）。
- **累计计数**：用成员变量 + `Init` 初始化 + 关闭「初始化」开关，实现累加。
