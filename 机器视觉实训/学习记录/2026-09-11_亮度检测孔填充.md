# 2026-09-11 · 亮度检测（循环）——孔填充检测

> **来源**：实操（VisionMaster 4.3.0）+ 案例《练习图片/亮度测量（循环）》（亮度检测说明.txt）+ 官方帮助《亮度测量》《Group》。关联《第4章_测量》《第11章_逻辑脚本》。
> **案例**：用**亮度检测 + 循环**检测工件孔是否被填充。**已完成（结果 OK）。**

## 一、案例目的与步骤（说明文件）

**目的**：检测工件的孔**是否被填充**（黑色孔洞=未被填充状态）；**若有一个孔被填充，则工件不合格**。

**步骤**：
```
1. 通过匹配对孔洞的位置进行初定位
2. 亮度测量继承匹配的区域，通过循环逐一检测每个匹配的孔洞亮度
3. 条件检测根据亮度的均值判断每个孔洞是否被填充
   （亮度均值为 100~180 表示孔洞未被填充）
4. 循环内的变量计算统计一个工件中未被填充的孔洞个数
5. 循环外的变量计算将未填充的孔洞和匹配到的孔洞个数做比较
6. 通过条件检测得出整个工件是否合格（全为黑色孔洞即为合格）
```

## 三、★ 关键：亮度检测的阈值设置（本次重点）

**核心参数是"亮度均值范围"**，决定孔径是否是"未填充"：
- **亮度均值为 100~180 → 孔洞未被填充**（合格特征）。
- 若某孔亮度均值**不在 100~180**（如偏暗）→ 该孔被视为**被填充**（不合格特征）。

**调参注意**：
- 阈值区间要**卡在"填充孔"和"未填充孔"的亮度之间**——两类的亮度分布要有明显间隔，取中间值作阈值。
- 阈值太宽 → 把填充孔也放过（漏检）；太窄 → 把正常孔误判为填充（误报）。
- 需结合实际打光：**保证"未填充孔"和"填充孔"的亮度差异足够大**，阈值才稳定。
- 亮度测量输出：最小/最大/**均值**/标准差、对比度、直方图(256)（官方）。

## 四、关键机制理解

### 1. 循环测每个孔
- 匹配给出**孔的位置（匹配框数组）**；
- **亮度测量继承匹配区域**（继承 ROI），用 **`[循环索引]`** 逐个遍历每个孔 → 每轮测一个孔的亮度；
- **证据**：Group 每轮输出一个 `var0:N`（N=1…16），共 16 个 → 循环体执行了 16 次，与工件 16 孔（2 行 × 8）一致。
- （同 0910 循环练习：`InputROI[循环索引]` 逐页翻数组。）

### 2. 循环内 vs 循环外的统计（两级判断）
- **循环内**：变量计算——累计"**未被填充的孔个数**"。
- **循环外**：变量计算——把"未填充孔数"与"**匹配到的孔数**"比较。
- **条件检测**：若两者相等（全部孔都未填充）→ 合格；否则有孔被填充 → 不合格。

> **本质**：**逐个孔判 + 汇总比较**。孔数由匹配给出，工件孔数变化也能自适应（本例 16 孔）。

## 五、要点串记

- **亮度检测判填充**：靠**亮度均值范围**（100~180=未填充），**阈值设置是成败关键**。
- **循环遍历孔**：亮度测量继承匹配区域 + `[循环索引]`，逐个孔测。
- **两级统计**：循环内数"未填充孔数" → 循环外与"匹配孔数"比较 → 条件检测判整件合格。
- **前提**：打光要让"填充孔 vs 未填充孔"亮度差异明显，阈值才好取。
