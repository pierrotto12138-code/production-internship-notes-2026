| 案例 | 循环用法 | 结果 |

> 结论：**循环能力在 0911 明显推进**（端子计数成功），但仍是**最薄弱环节**（胶囊未完成"逐颗定位+对应位置标注"）。**后续重点攻克 Group 循环与 `[循环索引]`。**

### 2. "分割/定位 → 条件分流 → 计数/标注"统一套路
```
目标分割/定位           →   条件判据        →   分流         →   输出
BLOB(面积) / 颜色识别 / 亮度测量  →  条件检测  →  分支字符/分支模块  →  格式化(计数+标签) + 通信
```

### 3. 反复踩到的坑：订阅必须手选数据类型
- 凡"订阅模块输出参数 + 索引"，**先手选 float/int 再订阅**；否则默认值带中文会导致识别不上 / 索引失效（0910 顶点检测、0911 条件检测都踩过）。
- 计数用变量计算要注意**初始化开关**：累计要"关"（用上次结果），比较要"开"。

### 4. 通信闭环
- **端子计数**：主流程首尾 + 三条颜色支路各发送数据（复用 0909 的 TCP 闭环，配 NetAssist）；
- **胶囊检测**：字符触发（TCP 发字符 `A` 触发流程，非 `A` 则异常）。

## 三、各案例一句话回顾

1. **亮度检测**：快速匹配初定位 → 图像增强 → **Group 循环内亮度测量**逐孔判填充 → 循环内/外两级统计 → 条件检测判整件是否合格。
2. **大小晶片分类**：BLOB 分割晶片 → 按**面积区间**分小/中/大 → 三路并行 `BLOB→条件检测→分支字符→格式化` → 格式化合并输出。
3. **端子计数（颜色）**：颜色转换(RGB→HSV) + 灰度匹配定位 → **颜色识别**判色 → **分支字符**按颜色分流 → 三色分别计数 → 通信发送。
4. **胶囊检测**：BLOB **个数**判漏放（少了）、BLOB **面积**判错放（不对）→ 分支模块分流 → 格式化输出"漏放 / 错料 / OK"。
