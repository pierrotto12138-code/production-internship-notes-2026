# 2026-09-09 · 圆弧边缘缺陷检测

> **来源**：实操（VisionMaster 4.3.0）+ 官方帮助《圆弧边缘缺陷检测》。关联《第5章_缺陷检测》《第3章_定位查找》。
> **案例**：圆弧边缘缺陷检测（环形零件外缘缺陷）。

## 一、模块用途与原理

- **用途**：检测工件/产品上的**弧边缘缺陷**，如断裂、凹陷、凸点、磨损等。
- **原理**：在圆弧上**自动创建一定数量的卡尺**，比对**相邻卡尺中部分圆弧中心点的 X/Y 轴和角度偏移**，并根据**预设阈值**判断缺陷是否成立。
- 检测结果：**红框**标注缺陷部位，**绿点**为正常圆弧边缘。
- 前序：图像源；**加圆查找可更精确定位目标**。

## 二、关键参数（本任务配置，圆弧件）

| 参数 | 配置 | 作用 |
|------|------|------|
| **边缘类型** | 最强 | 找最明显的边 |
| **边缘极性** | 任意极性 | 按边缘明暗 |
| **滤波尺寸** | 4 | 增强边缘抑噪（最小1，模糊时调大）|
| **边缘阈值** | 80 | 梯度阈值0~255；越大抗噪越强、边缘越少 |
| **卡尺高度** | 5 | 环形分布边缘点查找ROI的高度 |
| **卡尺宽度** | 7 | 采样宽度 |
| **卡尺间距** | 3 | 每个ROI之间的像素间距 |
| **缺陷极性** | 轨迹两侧缺陷 | 轨迹左/右/两侧 |
| **缺陷距离阈值** | **10** | 边缘点距拟合直线的距离，**超过即候选缺陷点** |
| **缺陷尺寸使能** | 关 | 按尺寸进一步筛选缺陷 |
| **缺陷面积使能** | 关 | 按面积进一步筛选缺陷 |

## 三、参数调整要点（关键）

- **缺陷距离阈值**是核心：太小会把正常起伏也当缺陷（误报）；太大则漏检。本次设 **10**。
- **卡尺间距**：太密 → 同一处重复采样、易误报；太疏 → 漏检。本次 **3**（缺陷均匀分布，需保证每个都检出）。
- **卡尺宽度**：本次 **7**。
- **滤波尺寸**：本次 **4**（别太大，避免把真缺陷也平滑掉）。
- 需**打开缺陷尺寸/面积使能**做二次筛选可进一步防误判（本次未开）。

## 四、本项目流程（缺陷检测项目）

```
36圆弧 → 37快速匹配1 → 40位置修正1 → 38圆查找1 → 39圆弧边缘缺陷检测
```

> 36圆弧定位 → 快速匹配 → 位置修正 → **圆查找（精定位圆）** → 圆弧边缘缺陷检测。

## 五、要点串记

- **圆弧边缘缺陷检测** = 沿弧布卡尺 + 比对相邻卡尺中心偏移 + 阈值判缺陷。
- **核心三参**：边缘阈值（抗噪）、卡尺间距（采样密度）、**缺陷距离阈值（判定灵敏度）**。
- **防误判**：调大缺陷距离阈值 + 打开尺寸/面积使能，过滤正常起伏与噪点。
- 配合**圆查找**做前序定位，检测更准。
