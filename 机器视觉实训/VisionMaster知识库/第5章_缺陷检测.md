# 第5章 缺陷检测：找瑕疵

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：缺陷检测、BLOB分析）。
> **本章定位**：**"有没有问题"的判断类核心。** 也是你玻璃板案例里要找"划痕"的那一步。
> **一句话原则**：缺陷检测 = 找到"不该出现"的东西，输出缺陷的位置、大小、个数。

---

## 5.0 速查表（缺陷检测家族全景）

| 类别 | 模块 | 检测对象 |
|------|------|---------|
| **表面相关** | 表面缺陷滤波 | 滤除表面噪声（预处理） |
| **边缘相关** | 边缘组合缺陷检测 | 单条边缘上的缺陷 |
|  | 边缘对组合缺陷检测 | 两条边缘之间的缺陷 |
|  | 边缘模型缺陷检测 | 边缘位置偏移/断裂/阶梯差 |
|  | 边缘对模型缺陷检测 | 边缘对宽度/位置偏移/气泡等 |
|  | 圆弧边缘缺陷检测 | 圆弧边缘上的缺陷 |
|  | 直线边缘缺陷检测 | 直线边缘上的缺陷 |
|  | 边缘位置趋势分析 / 边缘对位置趋势分析 | 沿边缘方向的间距趋势异常 |
| **字符相关** | 字符缺陷检测 | 字符缺笔画/糊字 |
| **几何形状** | 圆弧对缺陷检测 | 两圆弧之间的缺陷 |
|  | 直线对缺陷检测 | 两直线之间的缺陷 |
| **异常** | 异常检测 | 无缺陷样本 vs 待测样本对比（AI类） |

> **选型口诀**：缺陷在**边上**→ 边缘类；缺陷在**两条边之间**（如宽度）→ 边缘对/直线对/圆弧对；缺陷在**表面**→ 表面滤波 + BLOB分析或异常检测；**字符**→ 字符缺陷检测。

---

## 5.1 关键输出结构（所有缺陷模块通用）

多个缺陷模块共享这些输出：

| 结构 | 内容 | 含义 |
|------|------|------|
| **模块状态** | int | 0=NG(红)，1=OK(绿) |
| **缺陷个数** | int | 检测到几个缺陷 |
| **缺陷框** | 中心X/Y、宽、高、角度 | 每个缺陷被框出来的矩形 |
| **缺陷尺寸** | float | 沿轨迹方向的缺陷长度 |
| **缺陷面积** | float | 缺陷框面积 |
| **缺陷类型** | int | 缺陷类型编号（见下） |
| **缺陷综合信息** | 最小/最大/平均宽度、近似面积 | 几何形状类缺陷的统计 |

### 缺陷类型编号（边缘对模型缺陷检测）
- **1**：边缘对宽度缺陷
- **2**：边缘对位置偏移
- **3**：边缘对阶梯缺陷
- **4**：边缘对断裂缺陷
- **5**：边缘对气泡缺陷
- **6**：边缘位置偏移
- **7**：边缘凸起或凹陷
- **8**：边缘断裂
- **9**：边缘阶梯缺陷

> **新手提示**：不用背编号，软件里会显示缺陷类型名称。知道"每条边/每对边"都有专门的缺陷检测模块即可。

## 5.2 异常检测（AI/统计类，值得了解）

- **原理**：先学一幅（或多幅）**无缺陷**的样本，得到"正常"的标准；检测时把待测图与之对比。
- **输出**：
  - **对比状态**：大于阈值输出 1（无缺陷 OK），小于阈值输出 0（有缺陷 NG）。
  - **标签**：OK / NG。
  - **分数**：异常程度评分（**异常越严重，分数越低**）。

> 适合：缺陷形态不规则、难用规则描述的场合（如划痕、脏污、水渍）。是"学习型"缺陷检测。

---

## 5.3 BLOB 分析（最常用的"找斑块"）

BLOB 分析不是缺陷专用，但**常配合缺陷检测找缺陷块**（连通域分析）。核心输出：

| 输出 | 含义 |
|------|------|
| **BLOB个数** | 找到几个 blob |
| **面积** / **总面积** | 每个/全部 blob 面积 |
| **质心点** | blob 的中心 X/Y |
| **最小外接矩形** | 长轴、短轴、角度 |
| **周长** | blob 轮廓周长 |
| **圆形度** | 形状接近圆的程度 |
| **矩形度** | 面积与最小外接矩形面积比 |
| **主轴角度** | blob 朝向 |

> 应用：划痕检测里，把二值化后的"白块"（缺陷）用 BLOB 分析数个数、算面积、定位质心。

## 5.4 典型流程（玻璃板划痕检测，接案例）

```
[图像源] → [模板匹配(找到玻璃)] → [绘制ROI(框出检测区)] → [缺陷检测/异常检测(找划痕)] → [输出结果(有/无/面积)]
```

- **模板匹配**：定位玻璃板。
- **ROI**：只框该查的那块，避开边缘反光。
- **缺陷检测**：找划痕。规则型划痕用"边缘/直线对缺陷检测"；不规则用"异常检测"或 BLOB 分析。
- **输出**：缺陷个数、缺陷框、缺陷面积，或 OK/NG 标签。

> **回顾你之前的案例**：你最初构思"模板匹配-定位-缺陷检测-定位-标定"，实际正确版本是"采集→模板匹配(含定位)→ROI→缺陷检测→输出"。**缺陷检测这一步**现在你真正理解了——它输出的就是**缺陷个数/缺陷框/面积**。

---

## 5.5 动手任务（学习者）

1. 拖入 **图像源 + 模板匹配 + 绘制ROI + 缺陷检测**，模拟玻璃板流程。
2. 观察**缺陷个数、缺陷框、缺陷面积**，以及模块状态是 OK 还是 NG。
3. 试用 **BLOB分析**：把二值化后的缺陷块做一个连通域统计，看面积和质心。
4. （进阶）试用 **异常检测**：先学一张干净样本，再测脏污图片，看分数/标签变化。
