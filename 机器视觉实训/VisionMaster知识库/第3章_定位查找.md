# 第3章 定位/查找：找到目标在哪

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：模板匹配、定位、图形定位、直线查找、圆查找、定位家族模块结果汇总）。
> **本章定位**：**视觉检测的骨架核心。** 任何"判断"之前，先要"找到东西在哪、什么角度"。
> **本章讲清**：①定位家族有哪些算子 ②最常用的 4 个怎么用 ③它们的输出结果能拿来干嘛。

---

## 3.0 速查表（定位家族全景）

| 算子 | 一句话用途 | 典型场景 |
|------|-----------|---------|
| **模板匹配** | 给一张标准样图，找画面里"跟它一样"的 | 找玻璃板/工件主体位置 |
| **图形定位** | 用"边缘提取+形状"定位，返回匹配框+直线 | 需要位置+朝向的场合 |
| **位置修正** | 根据定位结果，修正后续检测的坐标 | 工件位置不稳定时 |
| **直线查找** | 找一条直边，返回直线的起点/终点/角度 | 工件边缘、基准边 |
| **圆查找** | 找一个圆/圆环，返回圆心/半径/误差 | 圆孔、螺栓、圆形工件 |
| **椭圆查找** | 找一个椭圆 | 倾斜圆、透视圆 |
| **阵列圆查找** | 一次找多个按阵列排列的圆 | 刹车盘上的多孔 |
| **边缘交点** | 两条边相交的点 | 找角点、十字 |
| **四边形查找** | 找矩形/四边形轮廓 | 贴片、PCB、标签 |
| **卡尺工具** | 在一条线上找边（基础原理） | 精确测边缘位置 |
| **目标跟踪** | 追踪运动目标并跨线计数 | 流水线计数 |

> **选型口诀**：要"整体形状"→ 模板匹配；要"几何特征"→ 直线/圆/四边形查找；要"稳定位置"→ 图形定位 + 位置修正。

## 3.1 模板匹配（最通用，重点掌握）

### 原理（一张图看懂）

![](../../配图/知识库配图/GUID-8AFCC3E0-13F9-4005-B309-093D75F15A76-high.png)

- **模板图像**（如一个三角形）→ 特征提取 → **建立模板**（记下特征轮廓点）。
- **测试图像**（很多三角形）→ 特征提取 → **搜索匹配** → 输出**匹配结果**（位置/角度/得分）。

### 相似度得分（0~1，越接近 1 越像）

模板经过**平移(x,y) + 旋转(θ) + 缩放(scaleX/Y)**后与目标比对，**特征点对上的越多得分越高**。

> 示例对比：全部特征点对上 = 得分 1；约 70% 对上 = 得分 0.71。

![](../../配图/知识库配图/GUID-D31B77EC-76FB-42F4-B5F1-B3E2BA3284EB-high.png)

### 4 个子模块怎么选

| 子模块 | 定位特征 | 建议 |
|--------|---------|------|
| 快速匹配 | 边缘轮廓点 | 速度快、特征清晰 |
| 高精度匹配 | 边缘轮廓点 | 精度优先（推荐先试） |
| 轮廓匹配 | 边缘轮廓点 | 轮廓突出 |
| 灰度匹配 | 灰度值 | 依赖亮度/纹理 |

### 输出结果（下游能读）

- **匹配状态**：找到几个对象（如 `1;1;1;1;1` = 5 个）。
- **匹配个数**、**分数**（得分）、**尺度**（缩放倍数）。
- **匹配框**：把匹配对象框起来的矩形（中心/宽/高/角度）。
- **匹配点**：匹配到的中心点坐标 X/Y。
- **检测区域**：本次搜索的 ROI。

> 常见输出数据结构（匹配框/匹配点/检测区域/屏蔽区/掩膜）是**定位家族共用**的，见 §3.6。

## 3.2 图形定位

- **作用**：用"边缘提取 + 图形形状"来定位，比纯模板匹配更强调几何结构。
- **关键输出**：匹配框（位置）、**输出直线**（起点/终点/角度）、**尺度X/尺度Y**、**匹配状态**（成功/失败）。

> 适合：目标有明确直线边或几何轮廓、需要精确定位"位置+朝向"的场景。

---

## 3.3 直线查找

- **作用**：在指定区域内找一条直边，返回该直线的几何信息。
- **关键输出**：
  - **输出直线**（起点/终点）
  - **中点**（X/Y）
  - **直线角度**（相对水平，顺时针为正）
  - **拟合误差**（越小越好）
  - **边缘点个数**、**轮廓点状态**

> **常见用法**：找工件的基准边（作为测量的基准），后续配合"线线测量"量宽度、"中点"定位等。

---

## 3.4 圆查找

### 原理（3 步）

1. 在**圆环形 ROI** 内自动布置多个**卡尺区域**（黄色矩形）。
2. 在每个卡尺区域内**提取边缘点**（紫色 X）。
3. 把边缘点集**拟合成圆**（绿色圆）。

### 关键运行参数

| 参数 | 含义 | 调参经验 |
|------|------|---------|
| 扇环半径 | ROI 圆环的内/外径 | 与实际圆半径接近，精度更高 |
| 边缘类型 | 最强/最后一条/第一条 | 选目标那条边 |
| 边缘极性 | 黑到白/白到黑/任意 | 按实际边缘明暗变化 |
| 边缘阈值 | 梯度阈值(0~255) | 越大抗噪越强，数量越少 |
| 滤波尺寸 | 去噪，最小1 | 边缘模糊时调大 |
| 卡尺数量 | 扫描的卡尺个数 | 越多越精细、越慢 |
| 剔除点数 | 剔除离群点 | 离群点多时调大 |
| 拟合方式 | 最小二乘/huber/tukey | 离群点增多时依次换 |

### 输出结果（重点）

- **输出圆环**：圆心X/Y、内径、圆半径、圆起始角度、圆角度范围、**拟合误差**。
- **圆轮廓点**、**边缘点个数**、**检测区域**、**ROI圆弧**、**卡尺框**及卡尺框检测区、**屏蔽区多边形**。

> **注意**：单个"圆查找"只能找一个圆；找多个圆用 **Group+循环** 或 **阵列圆查找**（有规律排列时）。

> **应用示例**：组合圆查找 + 脚本 + 数据集合 + 圆拟合 + 点点测量，可测汽车刹车盘上 10 个小圆孔的**同心度**。脚本里用三角函数把 9 个孔坐标算出来（见源文档附的 C# 脚本）。

## 3.5 位置修正（进阶，重要）

- **作用**：根据定位模块输出的"位置+角度"，把后续模块的检测区域**跟着平移/旋转**，让检测点始终对准工件。
- **关键输出**：**位置修正信息** = 基准点（X/Y/角度/尺度）+ 运行点（X/Y/角度/尺度）。

> **为什么需要**：工件在皮带上位置会漂移。定位找到了工件，"位置修正"能让后续的测量/缺陷检测**始终作用在工件的正确位置上**，而不是固定坐标。这是实际项目几乎必配的一环。

## 3.6 共用数据结构（定位家族通用）

以下结构在多个定位模块中通用，**查一次即可**：

| 结构 | 内容 |
|------|------|
| **匹配框** | 中心X/Y、宽度、高度、角度 |
| **匹配点** | 匹配点X/Y |
| **检测区域** | ROI 中心X/Y、宽度、高度、角度 |
| **屏蔽区多边形** | 多边形点数、点集（不检测的区域） |
| **输出掩膜** | 二值掩膜图像 + 宽/高/像素格式 |
| **ROI圆弧** | 检测圆弧中心、内径、外径、起始角度、角度范围 |
| **输出圆环** | 圆心、内径、圆半径、起始角度、角度范围 |
| **卡尺框** | 卡尺中心、宽度、高度、角度 |
| **卡尺框检测区** | 检测区中心、宽度、高度、角度 |
| **输出直线** | 直线起点、终点 |

## 3.7 典型流程（定位 + 修正 + 检测）

```
[图像源] → [模板匹配(找到工件)] → [位置修正(平移/旋转到工件)] → [测量/缺陷检测(对准工件)]
```

- **模板匹配**给出工件的位置和角度。
- **位置修正**把基准点对到运行点，让下游"盯着"工件。
- 下游（测量/缺陷检测）就**不会因工件移动而测错地方**。

> 这就是"定位"在真实项目里真正的用法——**它通常不是终点，而是给下游打基础的**。

## 3.8 动手任务（学习者）

1. 拖入 **图像源**（本地图）+ **模板匹配**，用目标图创建一个模板，跑通"找到目标"。
2. 观察"模块结果"里的**匹配框、匹配点、分数、匹配个数**。
3. 换一张位置偏移的图，验证模板匹配仍能找到（理解"定位"的意义）。
4. 加一个 **位置修正**，看下游检测区域是否跟着工件移动。
5. 试 **圆查找**：在圆上画环形 ROI，观察输出圆心/半径/拟合误差。
