# 第4章 测量：量尺寸

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：测量、线线测量、点点测量、点线测量、线圆测量、圆圆测量）。
> **本章定位**：定位找到目标后，**量它的尺寸/角度/距离**。
> **一句话原则**：测量是"看图问数字"——输入几何元素（点/线/圆），输出距离、角度、坐标。

---

## 4.0 速查表（测量家族核心模块）

| 模块 | 测量对象 | 主要输出 |
|------|---------|---------|
| **点点测量** | 两个点 | 距离、中点、夹角 |
| **点线测量** | 点 + 直线 | 垂足距离（点到线的垂直距离）、最近/最远距离 |
| **线线测量** | 两条线 | 夹角、绝对距离、交点、角度标识点 |
| **点圆测量** | 点 + 圆 | 中心距离、最远/最近距离、连线角度 |
| **线圆测量** | 直线 + 圆 | 圆心到线的距离、角度、交点、垂足 |
| **圆圆测量** | 两个圆 | 圆心距离、连线角度、交点 |
| **亮度测量** | 区域灰度 | 最小值/最大值/均值/标准差/对比度/直方图 |
| **间距检测** | 两条边 | 测量宽度（间距）、边缘位置/极性 |
| **像素统计** | 区域内像素 | 阈值范围内像素数量、比率 |
| **直方图工具** | 区域灰度分布 | 直方图、峰值、中值、对比度、累积直方图 |

> **选型口诀**：测两个点的距离 → 点点；测点到边的垂直距离 → 点线；测两条边的夹角/宽度 → 线线；测圆相关的 → 圆类测量。

---

## 4.1 最常用的几个测量模块

### 点点测量
- **输入**：两个点（可由定位模块/圆查找提供）。
- **输出**：**距离**、**中点**（X/Y）、**角度**（两点连线相对 X 轴，顺时针正）。

> 应用：量零件上两孔的中心距。

### 点线测量
- **输入**：一个点 + 一条直线。
- **输出**：**垂足点**（点在线上投影）、**垂足距离**（点到线的垂直距离）、**垂足角度**、最近/最远距离。

> 应用：检查工件边缘到某孔的距离（边缘垂直距离）。

### 线线测量
- **输入**：两条直线。
- **输出**：**夹角**、**绝对距离**（两线 4 端点平均距离）、**交点**、**角度标识点**。

> 应用：量两平行边的间距（即工件宽度）、两斜边的夹角。

### 线圆测量
- **输入**：一条直线 + 一个圆。
- **输出**：**圆心到线的距离**、**角度**、**交点**（线圆相交点）、**垂足**。

### 圆圆测量
- **输入**：两个圆。
- **输出**：**圆心距离**、**连线角度**、**交点**。

> 应用：测两个圆孔中心距、同心度（配合圆查找）。

---

## 4.2 亮度/像素类测量（判断"明暗是否正常"）

| 模块 | 输出 | 应用 |
|------|------|------|
| **亮度测量** | 最小/最大/均值/标准差、对比度、直方图(256) | 判打光是否均匀、区域平均亮度 |
| **间距检测** | 测量宽度（间距）、边缘位置/极性 | 量两边缘之间的精确宽度 |
| **像素统计** | 阈值范围内像素数量、比率 | 判一块缺陷面积占比 |
| **直方图工具** | 直方图、峰值、中值、对比度、累积直方图 | 分析灰度分布、定阈值 |

---

## 4.3 共用数据结构（测量家族通用）

和定位家族一样，多个测量模块共用这些结构，**查一次即可**：

| 结构 | 内容 |
|------|------|
| **测量直线** | 起点X/Y、终点X/Y，角度 |
| **测量圆环** | 圆心X/Y、圆半径、内径、圆角度范围、圆起始角度 |
| **交点** | 交点X/Y |
| **垂足点** | 垂足点X/Y |
| **测量点** | 测量点X/Y |
| **检测区域** | ROI 中心X/Y、宽/高/角度 |
| **ROI圆弧** | 检测圆弧中心、内/外径、起始角度、角度范围 |
| **输出掩膜** | 二值掩膜图像 + 宽/高/像素格式 |

> 这些结构和定位家族的**检测区域/ROI圆弧/输出掩膜是同一套**，学习时可以交叉对照。

---

## 4.4 典型流程（定位 → 测量）

```
[图像源] → [模板匹配(找到工件)] → [圆查找(找到孔)] → [点点测量(两孔中心距)]
```

- 圆查找找到两个圆孔，输出**圆心点**。
- 点点测量吃这两个圆心点，输出**中心距**。
- 至此完成"测量"：得知两孔中心距是多少像素。

> **重要**：这里量出的是**像素**。如果要输出**毫米**，需要**标定**（见第6章）把像素换成真实尺寸。

## 4.5 动手任务（学习者）

1. 用**圆查找**找两个孔，观察输出的圆心X/Y。
2. 加**点点测量**，把两个圆心连起来，看输出的**距离**和**中点**。
3. 加**线线测量**量两平行边的宽度，观察**绝对距离**与**夹角**。
