# 第6章 标定：把像素变成毫米

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：标定、标定板标定、平移旋转标定）。
> **本章定位**：前几章量出来的是**像素**；业务要的是**毫米**。标定就是建立"像素↔物理尺寸"的换算关系。
> **一句话原则**：标定 = 用已知真实尺寸的参照物，算出"1个像素 = 多少毫米"，再让测量结果直接出物理单位。

---

## 6.0 速查表（标定家族全景）

| 模块 | 用途 | 适用 |
|------|------|------|
| **N点标定** | 用若干已知物理坐标的点，建立像素↔物理坐标转换 | 机械手/运动机构抓取定位 |
| **N图像标定** | 用多张图（机械手移动多位置）标定 | 手眼标定（相机跟机械手） |
| **标定板标定** | 用标准标定板（棋盘格/圆点阵列）标定单像素精度 | 相机镜头畸变、纯图像测量 |
| **相机映射** | 相机 A 与相机 B 之间的坐标映射 | 多相机系统 |
| **映射标定** | 两幅图/两坐标系的映射 | 双相机、大图拼接 |
| **畸变标定** | 校正镜头畸变 | 镜头有明显的桶形/枕形畸变 |
| **平移旋转标定** | 机械手平移+旋转联合标定 | 平移+旋转的抓取 |
| **旋转标定** | 单独标定旋转轴 | 旋转工位 |
| **标定加载** | 加载已存好的标定结果 | 换产不用重新标定 |

> **选型口诀**：只测图像尺寸（无机械手）→ **标定板标定**；配合机械手抓取 → **N点标定/平移旋转标定**；多相机 → **相机映射/映射标定**。

---

## 6.1 核心概念：几个关键输出

### 最常用的两个
| 输出 | 含义 |
|------|------|
| **像素精度** | **单个像素对应物理坐标系下的尺寸（mm/pixel）** ← 最常用 |
| **尺度** | 世界坐标单位长度对应的像素数（pixel/mm） |

### 标定板标定的完整输出
- **标定误差**：标定测量值与真实值之差。**相机标定允许误差 0.1~0.5 之间**。
- **尺度**、**像素精度**、**标定点**、**标定原点**、**坐标X向量/Y向量**。
- **平移X/Y**、**旋转**、**斜切**、**宽高比**。

> **误差意义**：标定误差越大，后续测量越不准确。**误差 > 0.5 要重新标定**（检查标定板是否放平、光照是否均匀、特征点是否提取全）。

### 旋转校准相关（手眼标定）
- **旋转轴图像点**、**旋转中心物理点**、**角度旋转一致性**（1=一致 / -1=相反）。
- **标定矩阵**：图像坐标系与物理坐标系的转换关系（标定加载模块输出）。

## 6.2 两种最常用标定怎么操作（给新手的流程）

### 标定板标定（图像测量，无需机械手）
1. 准备一块**标准标定板**（棋盘格或圆点阵列，已知格距/点距）。
2. 相机拍摄标定板，提取**角点/特征点**。
3. 模块算出**像素精度**（每像素=多少 mm）。
4. 后续测量结果 × 像素精度 = 真实尺寸（mm）。

### N点标定（配合机械手）
1. 让机械手移动到几个**已知物理坐标**的点（N个）。
2. 相机拍下每个点的**像素坐标**。
3. 软件建立"像素坐标 ↔ 物理坐标"的转换。
4. 之后相机测到某位置的像素坐标，就能换算回机械手要去的物理坐标。

---

## 6.3 典型流程（测量 + 标定）

```
[图像源] → [标定板标定(得到像素精度)] → [圆查找/测量(得到像素值)] → [计算结果=像素×像素精度(mm)]
```

- **标定**建立"像素→毫米"换算。
- **测量**得到像素。
- **业务结果** = 像素值 × 像素精度，即真实毫米数。

> **纠正一个小误解**：标定是**前置的一次性设置**，不是每次检测流程的最后一步。它算出一个"像素精度"，然后所有测量的像素结果都乘它出真实尺寸。

---

## 6.4 何时需要标定？何时不需要？

| 场景 | 需要标定吗 |
|------|-----------|
| 只判断"有没有划痕/缺陷"（有/无） | ❌ 不需要 |
| 要报"划痕长 0.8mm""宽 15.2mm" | ✅ 需要（标定板标定即可） |
| 相机配合机械手抓取/贴合 | ✅ 需要（N点标定/平移旋转标定） |
| 多相机协同 | ✅ 需要（相机映射/映射标定） |
| 镜头畸变明显 | ✅ 需要（畸变标定） |

> 这正好印证了你玻璃板案例里的判断：**只判有无划痕，不需要标定**；要报真实尺寸才需要。

## 6.5 动手任务（学习者）

1. 看一下 `CalibGuideSample` 里的 `static.prc` / `dynamic.prc` / `reflect.prc`（这是官方**标定引导**示例方案，见"例程解读"文档）。
2. 拖入 **标定板标定**，用一张标定板图片跑一次，看**像素精度**和**标定误差**。
3. 记录误差，若 >0.5，试着调整标定板位置/光照/特征提取，重新标定，直到误差在 0.1~0.5。
4. 理解：你把测量模块的像素结果 × 像素精度，就得到真实毫米尺寸了。

> 标定是进阶内容，但要出"真实尺寸"绕不开它。先把核心概念（像素精度、标定误差、误差别超0.5）记牢即可。
