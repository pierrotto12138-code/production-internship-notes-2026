# 第9章 识别：读码、字符(OCR)

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：二维码识别、条码识别、字符识别）。
> **本章定位**：识别是"从图里读出信息"。**二维码/条码读一串码**，**字符识别(OCR)读一个字**。
> **一句话原则**：识别 = 读码/读字，输出**字符串** + 位置。

---

## 9.0 速查表（识别家族）

| 模块 | 读什么 | 输出 |
|------|--------|------|
| **二维码识别** | QR码 / DataMatrix码 | 编码信息、码个数、码角度、矩形框 |
| **条码识别** | 一维条码（条形码） | 编码信息、位置 |
| **字符识别(OCR)** | 印刷/打印字符 | 识别出的字符串、每个字符框 |
| **DL读码 / DL字符识别** | 深度学习版读码/OCR | 复杂场景更鲁棒 |

> **选型口诀**：方块码→二维码；粗细条纹→条码；一排字→字符识别；码难读/脏污→DL 系列。

---

## 9.1 二维码识别（最常用）

**支持类型**：**QR码** 和 **DataMatrix码**。

### 关键参数
| 参数 | 含义 | 建议 |
|------|------|------|
| QR码/DataMatrix | 是否启用某类型 | **不确定时都开启** |
| 二维码个数 | 期望最多识别几个 | 设场景码数最大值 |
| 极性 | 白底黑码/黑底白码/任意 | 按实际 |
| 边缘类型 | 连续型/离散型/兼容 | 兼容可通吃 |
| 降采样倍数 | 越大越快但识别率降 | 默认即可 |
| 镜像模式 | 镜子反射图 | 反射场景选镜像 |
| QR畸变 | 平面/瓶体褶皱 | 软包/瓶身选畸形 |
| 超时退出时间 | 超过就退出(ms) | 防死循环 |

### 关键输出
- **码个数**、**码状态**（识别成功与否）。
- **编码信息**（string）：码蕴含的信息 ← 核心。
- **码角度**、**矩形框**（中心/宽/高/角度）、**PPM**（最小模块像素）、**评估版本**（101=DM码，102=QR码）。

> **应用**：读取产品码（追溯、防伪）、配合定位/通信（把读到的码发给PLC）。

---

## 9.2 条码识别

- **对象**：一维条形码。
- **输出**：编码信息（字符串）、位置。
- **与二维码的区别**：一维条码只存横向信息，容量小；二维码二维存储，容量大、纠错强。

---

## 9.3 字符识别（OCR）

- **作用**：识别图像中的**字符**（印刷/打印文字），输出字符串。
- **关键输出**：识别出的文本、每个字符的框、字符状态。
- **应用**：读生产日期、序列号、喷码、钢印（对应参考资料"圆环展开（字符识别）"）。

> **预处理建议**：OCR 前常先做 **图像处理**（二值化/滤波）提字符清晰度；字符带弯曲/环形时，先 **圆环展开** 摊平再识别。

---

## 9.4 典型流程（读码）

```
[图像源] → [图像处理(预处理)] → [二维码识别/条码识别/字符识别] → [逻辑脚本(处理字符串)] → [通信(发给PLC)]
```

- 图像处理让码/字更清晰。
- 识别模块读出**编码信息**。
- 逻辑脚本可对字符串做判断（如校验日期）。
- 通信把结果发给上位机/PLC（见第12章）。

---

## 9.5 动手任务（学习者）

1. 用一张**二维码**图，拖入 **图像源 + 二维码识别**，读码看**编码信息**和**码个数**。
2. 试 **条码识别** 读一维码。
3. 试 **字符识别** 读一排印章/日期字符，看识别字符串。
4. 到 `课程案例\` 的 **"04-工业视觉二维码、条形码、字符识别"** 项目练手。
5. （进阶）如果码很难读，先加 **图像处理**（二值化/滤波）预处理，或改用 **DL读码**。
