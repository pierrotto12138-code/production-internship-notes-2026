# 第12章 通信：上位机对接

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：基本通信协议、通信数据收发控制、通信管理、PLC协议）。
> **本章定位**：VisionMaster 处理完图像后，要把结果**发给外部设备**（PLC、机械手、上位机）。
> **一句话原则**：通信 = VisionMaster **接收指令**（触发检测）+ **发送结果**（告知OK/NG/坐标）。

---

## 12.0 速查表（通信家族）

| 模块 | 干什么 |
|------|--------|
| **通信管理/设备管理** | 添加、配置通信设备（TCP/UDP/串口/PLC） |
| **发送数据** | 把结果发给外部设备 |
| **接收数据** | 读外部设备发来的数据 |
| **发送事件 / 接收事件** | 通过事件收发数据 |
| **协议解析 / 协议组装** | 解析/组装协议数据 |
| **心跳管理** | 设备间保持连接的心跳 |
| **响应配置** | 配置响应 |

## 12.1 四种基础协议（怎么配）

先打开**通信管理 → 设备管理**，点 **+** 添加设备，选协议类型。

| 协议 | 关键参数 | 适用 |
|------|---------|------|
| **TCP客户端** | 目标IP、目标端口 | 主动连别人的服务端 |
| **TCP服务端** | 本机IP、本机端口 | 等别人连你 |
| **UDP** | 本机IP/端口、目标IP/端口 | 无连接、广播 |
| **串口** | 串口号、波特率、数据位、校验位、停止位 | 工业设备常见 |

### 共用的通用参数
- **数据上传**：外部数据是否上传给软件显示/使用。
- **自动重连**：断开后自动重连。
- **接收结束符**：按结束符(`\r`/`\n`/`\r\n`或自定义)切分数据，**解决黏包/分包**。

> **新手提醒**：联调时常用 **TCP** 和 **NetAssist（网络调试助手）** 模拟通信（参考资料里有 `NetAssist(1).exe`）。

---

## 12.2 典型通信流程（PLC 交互）

```
外部设备(PLC)  →发送指令→  接收数据(触发检测)  →  VisionMaster运行方案
VisionMaster结果  →发送数据→  外部设备(PLC) 接收OK/NG/坐标
```

- **接收指令**：PLC 发个触发信号，VisionMaster 开始检测（触发模块/字符触发）。
- **发送结果**：VisionMaster 检测完，把 **OK/NG、坐标、测量值** 打包发给 PLC。

---

## 12.3 场景举例

| 场景 | 通信动作 |
|------|---------|
| PLC 叫 VisionMaster 检测 | PLC发指令 → 触发模块启动流程 |
| VisionMaster 告诉 PLC 结果 | 发送数据把 OK/NG 给 PLC |
| 读到二维码后上传 | 识别结果 → 发送数据给上位机 |
| 机械手要坐标 | 检测出坐标 → 发给机械手控制器 |

> 具体示例见官方 **"应用示例：通信数据收发控制"**（第13章会讲）。

## 12.4 动手任务（学习者）

1. 打开**通信管理**，添加一个 **TCP客户端** 设备，填目标IP/端口。
2. 用 **NetAssist** 开个 TCP 服务端，测试 VisionMaster 能否连上。
3. 在**发送数据**模块发送一条消息，看 NetAssist 能否收到。
4. 配置**接收结束符**，处理黏包/分包。
5. 理解：检测结果如何通过发送数据告诉 PLC。
