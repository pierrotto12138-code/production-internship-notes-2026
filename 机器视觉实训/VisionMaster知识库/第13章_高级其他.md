## 13.1 完整实战示例：通信数据收发控制（重点）

> 这是个**贯穿本章纲领**的完整案例，把"接收触发 + 多类型数据输出 + 发回服务端"串起来了。

### 业务需求
1. VM 作为 **TCP 客户端**，收到**服务端**（上位机 / 网络调试工具）发来的**任意字符串**时，触发流程执行。
2. 流程执行完，输出 **int / float / string / bytes / image / ROIBOX** 六种类型数据。
3. 这 6 种数据要**回传给 TCP 服务端**。

### 搭建思路（4 步）
| 步骤 | 做什么 |
|------|--------|
| **1. 配置 TCP 客户端** | 通信管理添加 TCP（如 127.0.0.1:7920），开启**数据上传+自动重连** |
| **2. 搭流程** | 接收数据 → 图像源 → 各算子模块 → 脚本 → 发送数据 |
| **3. 写脚本** | 在脚本里用 Get*/Set* 读写 6 种类型变量 |
| **4. 配全局触发** | 设为"字符串触发→不匹配→执行流程" |

### 流程结构
```
[接收数据] → [图像源] → [各算子模块] → [脚本(6种类型出入)] → [发送数据→TCP服务端]
```

> 图中箭头表示**执行顺序**（不是数据流）：`接收数据`输出的是字符串/字节，不会被当作图像传给图像源；流程也可由"全局触发"按收到的字符串启动。

### 脚本核心（6 种类型收发）
```csharp
// int
GetIntValue("in0", ref na);  SetIntValue("out0", na);
// float
GetFloatValue("in1", ref fa); SetFloatValue("out1", fa);
// string
GetStringValue("in2", ref s); SetStringValue("out2", s);
// bytes(16进制)
GetBytesValue("in4", ref b);  SetBytesValue("out4", b);
// image
GetImageValue("in3", ref img); SetImageValue("out3", img);
// roibox
GetRoiboxValue("in8", ref roibox); SetRoiboxValue("out8", roibox);
```
> 用 `ShowMessageBox` 在异常时弹窗提示（配合 try/catch）。

### 效果
用网络调试工具（如 NetAssist）测试，VM 收到字符串触发流程，输出的 6 种数据全发回 TCP 服务端。

> **这个案例的意义**：它是**你以后做任何"通信对接"项目的模板**——触发→处理→回传，几个步骤就讲通了。

## 13.4 许可 / 授权（加密狗）

VisionMaster 是商业授权软件，使用需要**许可证**：

| 授权方式 | 说明 |
|---------|------|
| **本机加密狗** | 插在本机的加密狗 |
| **远程加密狗** | 网络上的加密狗服务器 |
| **通过授权码** | 输入授权码激活 |
| **读取加密狗序列号** | 工具查看狗序列号 |

> 相关主题：`获取软件使用许可`、`通过本机/远程加密狗`、`通过授权码`、`读取加密狗序列号工具`。如果软件提示"未授权/试用过期"，检查加密狗是否插好、驱动是否装、授权方式选对。

## 13.5 动手任务（学习者）

1. 仔细读一遍 **§13.1 通信数据收发控制** 案例，理解"触发→处理→回传"的完整链路。
2. 用 **NetAssist** 开个 TCP 服务端，试着按这个案例搭一个最小流程（接收→脚本→发送）。
3. 找到 `Applications\Tools\` 下的工具，看看**环境检测工具**、**版本切换助手**是干嘛的。
4. 如果软件提示授权问题，检查加密狗/授权码对应的授权方式。
