# 第7章 图像处理：预处理

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：图像滤波、图像二值化、形态学处理、图像运算、图像增强、图像缩放、图像拼接、仿射变换、畸变校正）。
> **本章定位**：给"判断类算子"做**预处理**。缺陷检测、识别、定位之前，常先修一下图像质量。
> **一句话原则**：图像处理 = 让目标更清晰、噪声更少、特征更突出，**为下游算子服务**。

---

## 7.0 速查表（图像处理家族）

| 模块 | 一句话用途 | 什么时候用 |
|------|-----------|-----------|
| **图像滤波** | 去噪声、平滑、提取边缘 | 图上有噪点/毛刺时 |
| **图像二值化** | 把灰度图变成黑/白两值 | 想抓住"目标轮廓" |
| **形态学处理** | 腐蚀/膨胀/开运算/闭运算 | 二值图后去小杂点/补缺口 |
| **图像运算** | 加/减/乘/除、取反 | 背景差分、增强对比 |
| **图像增强** | 提亮、对比度、归一化 | 曝光不足/过曝 |
| **图像缩放** | 放大/缩小 | 分辨率不匹配 |
| **图像拼接** | 多图拼成一张大图 | 大幅面工件 |
| **仿射变换** | 平移/旋转/缩放整张图 | 把图摆正、对位 |
| **畸变校正** | 校镜头桶形/枕形畸变 | 镜头有变形 |

> **选型口诀**：先**滤波**去噪 → 需要黑白轮廓就**二值化** → 再**形态学**清理 → 要几何变换就**仿射/校正**。

---

## 7.1 图像滤波（最常用）

### 五种滤波算法

| 滤波 | 类型 | 原理一句话 | 适用 |
|------|------|-----------|------|
| **高斯滤波** | 低通 | 按高斯曲线给窗口内像素加权 | 抑高斯噪声，平滑 |
| **中值滤波** | 非线性 | 取窗口内像素灰度**中值** | **去椒盐噪点**，保边最强 |
| **均值滤波** | 低通 | 取窗口内像素灰度**均值** | 平滑抑噪 |
| **取反** | — | 黑白反转 | 切换背景/目标 |
| **边缘提取** | — | 梯度→非极大值抑制→双阈值 | 提取边缘（类似Canny） |

### 关键参数
- **高斯滤波核**：窗口大小(1~101)。**核越大越模糊**，丢的高频信息越多。
- **滤波核宽度/高度**：中值/均值滤波的窗口尺寸，越大越模糊。
- **边缘阈值范围**（边缘提取）：0~255，越大抗噪越强、边缘越少。

> **新手提示**：图上有明显噪点（椒盐噪点）优先用**中值滤波**；只是想让边缘更平滑用**高斯滤波**。核尺寸从 3、5 试起，别一上来就 15（会糊）。

### 应用示例（官方）
图像增强 + 图像滤波去噪 → 轮廓匹配圆环 → 圆查找做同心圆检测。

## 7.2 图像二值化

**作用**：把灰度图变成**只有 0（黑）和 255（白）**两值，突出目标轮廓，方便后续识别/测量/分割。

### 五种二值化方式

| 方式 | 原理 | 适用 |
|------|------|------|
| **硬阈值** | 设高/低阈值，在范围内置255 | 光影影响小的环境 |
| **均值二值化** | 原图−均值背景图，按差值和比较类型判定 | 平滑消噪 |
| **高斯二值化** | 原图−高斯背景图，按差值和比较类型判定 | 保特征+消噪 |
| **Sauvola二值化** | 按局部均值+标准差×系数判定 | **背景单一、光照不均匀** |
| **自动二值化** | 最大类间方差法自动算阈值 | 不用设参数，最省事 |

> **新手建议**：不知道设多少阈值时，先试**自动二值化**；如果光照不均（有的亮有的暗），用 **Sauvola**（亮/暗背景可选）。

## 7.3 形态学处理

**作用**：在二值图上做结构操作，**去小杂点、补缺口、连断点**。

常用操作（对二值图）：
- **腐蚀**：让白色（目标）变瘦 → 去掉小的噪点。
- **膨胀**：让白色变胖 → 填充小孔、连断点。
- **开运算**：先腐蚀后膨胀 → 去噪点且保存大体形状。
- **闭运算**：先膨胀后腐蚀 → 补缺口。

> 用于：二值化后还有零散小白块（噪声）→ **开运算**清掉；目标中有小孔 → **闭运算**补上。

---

## 7.4 图像运算 / 增强 / 变换

### 图像运算
- 加/减/乘/除、取反。**加减**常用于**背景差分**（去掉固定的背景，突出变化的物体）。

### 图像增强
- 提亮、提升对比度、归一化、阴影校正。用于**曝光不足/过曝**导致看不清时。

### 几何变换类
| 模块 | 用途 |
|------|------|
| **图像缩放** | 改分辨率 |
| **图像拼接** | 多图拼大图 |
| **仿射变换 / 逆仿射** | 平移/旋转/缩放整图，摆正工件 |
| **畸变校正** | 校镜头桶形/枕形变形 |
| **圆环展开** | 把圆环展开成直条（配合读码/字符） |

---

## 7.5 典型流程（预处理 → 检测）

```
[图像源] → [图像滤波(去噪)] → [图像二值化(抓轮廓)] → [形态学(清理)] → [缺陷检测/识别/测量]
```

> 这就是为什么第5章缺陷检测常搭配图像处理：**先修图，再检测**，误检率会低很多。

## 7.6 动手任务（学习者）

1. 拖入 **图像源 + 图像滤波**，选**中值滤波**，核从 3 调到 15，观察噪点变化（越模糊）。
2. 加 **图像二值化（自动）** 看黑白效果；改 Sauvola 试光照不均的图。
3. 二值化后加 **形态学（开运算）** 清小噪点、**闭运算**补孔。
4. 试用 **圆环展开**，把圆环图展开成直条（参考资料里"圆环展开（字符识别）"练习）。
5. 到 `课程案例\练习图片/` 里找"塑料片缺陷检测""焊点检测"的图，用滤波+二值化预处理练手。
