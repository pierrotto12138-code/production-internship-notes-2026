# 第10章 深度学习（DL算子）

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：深度学习、DL目标检测、DL分类、DL图像分割、DL实例分割）。
> **本章定位**：当**规则算法不好用**、缺陷/目标形态不规则时，用 **深度学习** 建模识别。
> **一句话原则**：深度学习 = **先训练模型**（喂一批样本），再运行模型去检测/分类/分割。

---

## 10.0 速查表（深度学习家族）

| 模块 | 干什么 | 输出 |
|------|--------|------|
| **DL目标检测** | 框出图里多个目标+类别 | 目标个数、类别、置信度、目标框 |
| **DL分类** | 判断整个区域属于哪一类 | 类别名称、类别概率、置信度 |
| **DL图像分割** | 逐像素分类（像素级） | 类别图、类别信息、概率图 |
| **DL实例分割** | 分割出每个目标的轮廓 | 目标个数、轮廓点、掩膜、渲染图 |
| **DL快速图像分割** | 更快的分割 | 类别图、类别名、灰度值 |
| **DL无监督分割** | 不用标注的分割 | 概率图 |
| **DL异常检测** | 判断是否异常（学习正常样本） | 残差图 |
| **DL图像检索** | 找最相似的注册图像 | 类别、相似度、图像索引 |
| **DL读码 / DL字符识别** | 深度学习版读码/OCR | 见第9章 |

## 10.1 三个最核心的 DL 算子

### DL 目标检测
- **作用**：在图像上**框出**所有目标，并给出**类别**和**置信度**。
- **输出**：**目标个数**、**目标类别**、**目标置信度**（越接近1越准）、**目标框**（中心/宽/高/角度）。

> 应用：找出图里所有零件/缺陷，并判断各自是什么。

### DL 分类
- **作用**：判断整张图（或区域）**属于哪一类**（好/坏、A类/B类）。
- **输出**：**类别名称**、**类别概率**、置信度（类别1概率−类别2概率）。

> 应用：判断"这个产品OK还是NG"，纯二分类最简单。

### DL 图像分割 / 实例分割
- **图像分割**：**逐像素**标出每类像素（语义分割），输出**类别图**。
- **实例分割**：分割出**每个独立目标**的轮廓，输出**目标个数、轮廓点、掩膜、渲染图**。

> 应用：像素级找缺陷区域（分割比框更精确）；统计多个独立目标。

## 10.2 深度学习的工作方式（新手必懂）

传统算子（模板匹配、边缘查找）是**人为设计规则**；DL 是**数据驱动**：

```
收集样本 → 标注 → 训练模型 → 部署到VisionMaster → 运行时推理
```

- **样本**：要喂一批有代表性的图（好的+坏的、各种角度）。
- **标注**：标出"这是什么目标/缺陷"。
- **训练**：算法自己学特征（外部工具/训练平台完成）。
- **部署**：把训练好的**模型文件**导入 VisionMaster 的 DL 模块。
- **推理**：运行时，模块用模型对新图做检测/分类/分割。

> **新手提醒**：DL 需要**大量、多样、干净的标注样本**，样本质量直接决定效果。规则算法能解决的就别上 DL（DL 需要数据、训练、更吃资源）。

---

## 10.3 关键输出概念（DL 通用）

| 概念 | 含义 |
|------|------|
| **置信度** | 识别的可靠度，越接近 1 越靠谱 |
| **类别名称** | 从模型文件里取的类别名 |
| **概率图 / 类别图 / 残差图** | 输出的图像结果（分割/异常用） |
| **掩膜 / 渲染图** | 实例分割的输出：遮罩图 / 上色图 |
| **目标状态** | 1=检测到，0=未检出 |

> 置信度低（如 <0.5）通常是误检/漏检，常见原因：样本不足、光照变化、目标外观差异大。

---

## 10.4 选型口诀

| 你要什么 | 用哪个 DL 算子 |
|---------|---------------|
| 框出目标个数+类别 | **DL目标检测** |
| 判定整图 OK/NG | **DL分类** |
| 像素级找缺陷区域 | **DL图像分割** |
| 逐个目标精确轮廓 | **DL实例分割** |
| 判断是否异常（无标注） | **DL异常检测** |
| 找最相似的标准图 | **DL图像检索** |

## 10.5 动手任务（学习者）

1. 了解 DL 模块的**模型导入/配置**流程（找到模型文件加载入口）。
2. 尝试 **DL分类**：加载一个已训练的二分类模型，看输出**类别/置信度**。
3. 尝试 **DL目标检测**：看能否框出多个目标、给出置信度。
4. 理解**置信度**调低的后果（误检增多）与调高的后果（漏检增多）。
5. 思考：为什么"规则算法能解决的就别用DL"？（DL 要数据/训练/资源）
