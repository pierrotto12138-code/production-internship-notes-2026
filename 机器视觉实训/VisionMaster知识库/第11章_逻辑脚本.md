# 第11章 逻辑/脚本：流程控制与编程

> **来源**：VisionMaster 4.3.0 帮助系统蒸馏（主题：脚本、脚本开放接口、流程控制、逻辑工具）。
> **本章定位**：当"拖积木"不够、需要**条件判断、循环、自定义计算**时，用**逻辑/脚本**。
> **一句话原则**：脚本 = 用 **C#** 写一小段代码，操控流程数据与执行逻辑。

---

## 11.0 速查表（逻辑/脚本家族）

| 模块 | 干什么 |
|------|--------|
| **脚本** | 用 C# 写代码，读写变量/全局变量/模块结果、发通信数据 |
| **全局脚本** | 控制**整个方案**所有流程的执行逻辑 |
| **条件分支** | 按条件走不同分支 |
| **分支模块 / 分支字符** | 按条件/字符分支 |
| **条件检测** | 条件判断输出 OK/NG |
| **逻辑 / 运算** | 做逻辑或算术运算 |
| **数据集合 / 数据队列** | 收集、缓存、传递数据 |
| **文本保存 / 格式化** | 格式化、保存文本 |
| **耗时统计** | 统计模块耗时 |

---

## 11.1 脚本模块（重点）

用 **C# 语言**编写自定义逻辑，操控制流程。

### 两个核心方法

| 方法 | 何时运行 | 干什么 |
|------|---------|--------|
| **Init()** | 加载方案/预编译时 | 变量初始化、创建句柄 |
| **Process()** | 每次流程执行时 | 变量计算、逻辑处理 |

### 变量类型（六种）
`int`、`float`、`string`、`bytes`、`image`（图像）、`ROIBOX`（ROI框）。

### 常用脚本接口（能干什么）
- **读写输入/输出变量**：`GetIntValue`/`SetIntValue`、`GetFloatValue`/`SetFloatValue`、`GetStringValue`/`SetStringValue`、`GetBytesValue`/`SetBytesValue`、`GetImageValue`/`SetImageValue`、`GetRoiboxValue`/`SetRoiboxValue`（含数组版本）。
- **读写全局变量**：`GlobalVariableModule.GetValue`/`SetValue`。
- **读取模块结果**：`CurrentProcess.GetModule("模块名").GetValue("输出参数")`。
- **设置模块参数**：`CurrentProcess.GetModule("模块名").SetValue("参数名","值")`。
- **发送通信数据**：`GlobalCommunicateModule.GetDevice(序号).SendData(...)`。

### 默认代码骨架
```csharp
public partial class UserScript:ScriptMethods,IProcessMethods {
    int processCount;
    public void Init() { processCount = 0; }   // 初始化
    public bool Process() {                     // 每次执行
        // 写你的逻辑
        return true;
    }
}
```

> **记住**：脚本里的模块名要**对应流程里真正的模块名**（如"BLOB分析1"）；在 Group 里的模块要带 Group 名（如"组合模块1.BLOB分析1"）。

## 11.2 条件分支 / 循环（流程控制）

- **条件分支**：根据某个变量/结果，**走不同分支**（A路径或B路径）。
- **分支模块**：按条件分流。
- **Group + 循环**：配合"循环功能"可对多个对象批量执行（如：循环所有圆孔做测量）。

> 这正是圆查找那个刹车盘案例的实现思路——用**脚本算9个孔坐标** + **循环**逐个处理。

---

## 11.3 应用示例

**圆查找案例**（第3章提到）：用脚本把 10 个孔的坐标算出来，组合 圆查找+数据集合+圆拟合+点点测量，测同心度。脚本里用三角函数：
```csharp
for(int i=1;i<10;i++){
    x[i-1] = (float)((x1-x0)*Math.Cos(36*i*Math.PI/180) - (y1-y0)*Math.Sin(36*i*Math.PI/180) + x0);
    y[i-1] = ...;
}
SetFloatArrayValue("x2", x, 0, 9);
```
> **这个例子说明了脚本的威力**：纯拖积木难做的计算，用一段 C# 就搞定了。

## 11.4 动手任务（学习者）

1. 拖入 **脚本** 模块到流程里，打开脚本编辑窗口，看默认的 `Init`/`Process` 骨架。
2. 定义输入变量 `in0`、输出变量 `out0`，在 `Process` 里写 `out0 = in0 + 1`，验证能传值。
3. 在脚本里用 `GlobalVariableModule` 读写一个全局变量。
4. 试用 **条件分支**，按一个变量值决定走哪个分支。
5. 参考圆查找脚本，用脚本算一个圆的坐标。
