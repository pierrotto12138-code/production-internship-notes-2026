## 使用方式（给两种人）

### 作为操作者（上手查攻略）
1. 打开对应章节 `.md` 文件（如 `第3章_定位查找.md`）。
2. 每章先看"**速查表**"（算子名 + 一句话用途），再按需看"详细配置"。
3. 找不到的到 `01_索引目录\VisionMaster帮助主题索引.md` 按类目搜标题。

### 作为学习者（从头学）
1. 按主线 1→14 顺序读，每章配"**典型流程示例**"（含官方例程解读）。
2. 每章末尾有"**动手任务**"，建议在软件里实际搭。
3. 卡住了记标题到 `01_索引目录\` 查原文。

> **官方例程素材**：`<VisionMaster安装目录>\Applications\CalibGuideSample\`（static/dynamic/reflect）与 `ApplicationTemplate\`，解读见第14章。
